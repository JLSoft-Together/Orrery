# desktop — apps/desktop (Electron, Windows + macOS)

Paths are relative to `apps/desktop` unless they start at the repo root. Change history: `_meta.md`; plans `.planning/PLAN-v*.md`; docs §11j (shell), §11k (macOS).

Flow: `main.ts` `ready()` → `backups.applyPending()` → `createMainWindow()` + `showIntro()` (startup page shown first) → `CollectorHost.start()` as `earlyStart` (fork collector; port already healthy → fatal `port-in-use`) → IPC / preview / run setup → `boot()` reuses `intro` + `earlyStart` → BrowserWindow loads `http://127.0.0.1:<port>/` (WP-perf-5).

## Boot & main process

- `src/main.ts`: single-instance lock, AUMID / `appId` `dev.ccm.monitor`; `USER_DATA_DIR` pinned to `appData/Agent Monitor` before the lock (profile survives the GolAIm and Orrery renames); `lockPermissions` (notifications / clipboard / fullscreen, app origin only; `clipboard-read` for image paste); `harden` (window.open → `openAppWindow` or `shell.openExternal` http(s); cross-origin navigation blocked); main window (bounds `userData/window.json`, close = hide + one balloon), compact window (`?mode=compact`); tray (open / compact / start at login `--hidden` / logs / quit); `showIntro()` (`INTRO_MS`, `LEAVE_SCRIPT`) runs from `ready()` right after `createMainWindow()` (WP-perf-5); `boot()` awaits `intro ?? showIntro()` and `earlyStart ?? host.start()`, so retries (error page, retry link, `startCollector`) still start the host the old way. `session-end` stops `host?.stop()` because the window now exists before the host.
  - IPC in main: `ccm:pty-endpoint`, `ccm:pick-folder(near?)` (`src/pick-start.ts` `pickStartDir`), `ccm:logs`, `ccm:login-item`, `ccm:window-bg`, `ccm:appearance`, `ccm:zoom`, `ccm:window`, `ccm:statusline-state|enable`, `ccm:grant-folder`, `ccm:capture-rect`, `ccm:focus` / `ccm:select` / `ccm:pane-open` (page round trips), push `ccm:run-event`.

  - Every native confirm (quit, status line, folder access, full access, git delete, Run prompts, extensions, unsaved files) goes through `confirmBox(win, opts)` (first button = action).
  - Quit only via tray (`window-all-closed` no-op). `before-quit` → `confirmUnsaved` → `confirmQuit` (PTY census + live runs, default Cancel; asks even if census times out) → `stopRuns`, `stopPreview`, host / PTY stop, `allSettled` + 8 s `app.exit` deadline. `session-end` skips dialogs.

## Collector host

- `src/collector-host.ts` `CollectorHost`: `isHealthy` (`GET /health`); healthy port before fork = another collector → `FatalError('port-in-use')`, never borrowed (it would get the app key); `utilityProcess.fork(collector.cjs)`, output → `logs/collector.log` + 40-line `tail`; `stop()` posts `shutdown`, kill after 4 s; `ownsPort`; `onMessage`, `onExit`.
- Restart: exit 3 (`PORT_IN_USE_EXIT`, mirrors collector `server.ts`) → fatal, no restart; other exits → restart ≤ 3 times, then error page with log tail + retry (`boot()` resets the count). Boot waits `/health` 30 s.
- `collectorEnv`: `CCM_APP_KEY` (random per run), `CCM_TOAST_LINK` (win), `CCM_TOAST_BACKEND` (mac), `CCM_PORT`, `CCM_DATA_DIR`, `CCM_WEB_DIST`, `CCM_STATUSLINE_BRIDGE|COMMAND`, `CCM_CORE_PROCS` + `CCM_CORE_BIN` (via `coreProcsEnv`), + inherited env. The CJS bundle needs `CCM_WEB_DIST` / `CCM_STATUSLINE_BRIDGE` always set (`import.meta` fallbacks do not work).
- Desktop only (v2.0.0, PLAN-v19): `sendAppKey` adds `X-CCM-App` to `ORIGIN/*` + the collector WS; the collector 403s everything else. The window must load the http origin, never `file://` (collector origin check, WS URL from `location.host`).
