# shell — Tauri vỏ `apps/shell` (PLAN-v87 bước 6b, WP T0 + T1)

Cargo workspace riêng (`[workspace]` trống, `Cargo.lock` riêng, target `apps/shell/target`), không nằm trong workspace `apps/core`; link `core-serve` qua path. Tauri `=2.12.5` (feature `tray-icon`, `unstable`), `tauri-build =2.7.4`; plugin `single-instance` (+`deep-link`), `deep-link`, `autostart`, `notification`, `dialog`, `opener`. Binary `orrery-shell`; `windows_subsystem = "windows"` chỉ ở release.

## Khởi động (`main.rs`)
1. `config.rs` `ShellConfig::from_env`: key ngẫu nhiên 32 byte hex (`random_hex`, getrandom), cổng = `CCM_PORT` (0 = cổng trống); bản debug không có `CCM_PORT` → **4419**, không có `CCM_DATA_DIR` → `%TEMP%/orrery-shell-dev` (dev không bao giờ đụng 4317 / `%LOCALAPPDATA%\ccm`). `CCM_WEB_DIST` → `<exe>/web` → `apps/web/dist`. `CCM_CORE_BIN` → `<exe>/orrery-core(.exe)` → `apps/core/target/release/orrery-core(.exe)`. WebView2 profile = `CCM_SHELL_WEBVIEW_DIR` hoặc `<data>/shell-webview`. `ServeConfig::from_vars` với các giá trị đè (`CCM_APP_KEY`, `CCM_PORT`, `CCM_WEB_DIST`, data dir dev, `CCM_STATUSLINE_COMMAND` rỗng nếu chưa đặt), `CCM_HOST_RPC` luôn tắt (SystemDeps, không toast từ serve).
2. `serve.rs` `Serve::start`: `/health` đã trả lời trước khi chạy → `PortInUse` (không chạm app khác); `stdio::take_stdin()` thay stdin của process bằng pipe của mình (Windows `CreatePipe` + `SetStdHandle`, macOS `pipe` + `dup2`) vì `core_serve::run` đọc lệnh điều khiển từ stdin và EOF = tắt; chạy `core_serve::run(cfg)` trên thread `core-serve`; chờ `/health` (max 30 s), thread thoát mã 3 = cổng bận. `stop()` ghi `{"type":"shutdown"}` vào pipe, chờ max 4 s. `request()` = HTTP/1.1 tối giản (std `TcpStream`) cho `/health`, `/focus`, `/snooze` có header `x-ccm-app`.
3. Lỗi khởi động → `fail()` hiện dialog lỗi (strings vi/en) rồi thoát 1.
4. Tauri builder: single-instance (argv có `agent-monitor://` → `links::handle`, không thì hiện cửa sổ), deep-link `on_open_url` (macOS), autostart (`--hidden`), notification, dialog, opener; `manage(Shell)`; command duy nhất `ccm`; `on_window_event` → `window::on_window_event`. `setup`: `capability()` thêm lúc chạy capability `app` cho remote `http://127.0.0.1:<port>/*`, cửa sổ `main` + `compact`, quyền `core:default`, `start-dragging`, `internal-toggle-maximize`, `allow-ccm` (AppManifest trong `build.rs`). `ExitRequested` không mã → giữ app (tray); `Exit` → `Shell::shutdown` (pty rồi serve, một lần).

## Cửa sổ (`window.rs`, `header.js`)
- `create_main`: URL `http://127.0.0.1:<port>/?k=<key>` → core-http đổi sang cookie (`core-http/src/cookie.rs`), redirect `/`. Windows `decorations(false)` + `shadow(true)` (giữ `THICKFRAME` / `MAXIMIZEBOX`, snap phím chạy), macOS `TitleBarStyle::Overlay` + `hidden_title`. Nền theo `shell-appearance.json`. `on_navigation`: chỉ origin app (khác → trình duyệt ngoài, chặn); `on_new_window`: URL app → cửa sổ `compact`, còn lại → trình duyệt ngoài, luôn `Deny`. `on_page_load` Finished → `set_zoom(1.2^level)`. Vị trí / kích thước / maximize lưu khi đóng, chỉ phục hồi nếu còn nằm trên một màn hình.
- Close cửa sổ `main` → ẩn vào tray (lần đầu Windows: notification `hidden_notice`), trừ khi đang `quitting`.
- `init_script(origin)`: `(function(){const __ccmShell={platform, origin, sync:{ccm:core-serve:'rust', ccm:deepseek-enabled:false}}; if (location.origin!==origin) return; shim.js; header.js; webview.js})()` → chỉ trang app có `window.ccmDesktop`. Mỗi phần kết thúc bằng `;` (header.js kết thúc `})()`, thiếu `;` thì IIFE sau bị gọi như tham số → webview.js không chạy; test `the_init_script_ends_every_part_with_a_semicolon`).
- `on_permission_request`: trang app xin `ClipboardRead` → Allow (WebView2 mặc định hỏi; E2E agent-map đọc clipboard bằng `navigator.clipboard.readText`). `on_page_load` Started của `main` / `compact` → `guest::close_owned` (trang tải lại thì đóng hết child cũ). `set_zoom_all` → `guest::refresh_all` (vị trí child = CSS px × zoom trang).
- `header.js`: CSS chừa 138 px bên phải header (`header.ccm-titlebar[data-title-bar] > div`), nút min / max-restore / close tự vẽ (Windows, màu `--ccm-ink`, close hover `#c42b1c`) gọi `shell:window`; gắn `data-tauri-drag-region` lên header + phần tử không tương tác bên trong (MutationObserver chỉ trên header sau khi tìm thấy); Ctrl/⌘ `=`/`+`/`-`/`0` → `ccm:zoom` (như `before-input-event` của Electron).
- `tray.rs`: menu Mở dashboard / Cửa sổ gọn / Chạy cùng Windows (checkbox, chỉ bản release) / Mở thư mục log (= data dir) / Thoát; click trái = hiện cửa sổ. `quit()` lưu bounds, `shutdown`, `exit(0)` trên thread riêng.

## Shim `window.ccmDesktop`
- `scripts/gen-desk-shim.mjs` bundle `apps/desktop/src/preload.ts` bằng esbuild, thay module `electron` bằng bản giả: `ipcRenderer.invoke/send` → `__TAURI_INTERNALS__.invoke('ccm', {channel, args})`, `on/removeListener` → `plugin:event|listen/unlisten` (listener nhận `({}, payload)`), `sendSync` → `__ccmShell.sync`, `contextBridge.exposeInMainWorld` → `defineProperty` + `freeze`, `webUtils.getPathForFile` → `''`; `process.platform` → `__ccmShell.platform`. Xuất `apps/shell/src/shim.js` (minify khoảng trắng, không comment); `--check` báo shim cũ. Cùng tên method / event / cách đóng gói tham số như preload, nên `desktop.ts` của web không đổi (`hasTerminals` = có `ptyEndpoint`).
- `ccm.rs` command `ccm(channel, args)`: chỉ nhận webview có URL cùng origin app. T0 tự làm: `ccm:pty-endpoint`, `ccm:pick-folder` (dialog), `ccm:open-external` (http/https), `ccm:zoom` (bước 0,5, -3..3, % = 100·1.2^level), `ccm:window-bg`, `ccm:appearance` (`parse_look`), `ccm:locale` (đổi chữ tray), `ccm:login-item` (debug → null), `ccm:orrery-reply` / `ccm:focus-reply` (trả về `Shell::ask` đang chờ), `shell:window` (min / max / close / state). T1 thêm: `shell:guest` (child webview), `ccm:capture-guest`, `ccm:capture-rect` (base64; shim đổi lại `Uint8Array` qua `BINARY` trong `gen-desk-shim.mjs` vì IPC remote của Tauri đổi `Raw` thành mảng số), `ccm:clipboard-image`, `ccm:clipboard-image-file`. Kênh `ccm:*` khác → `desk.rs` `dispatch` (`core_desk::Desk::standard`, spawn_blocking, `Ctx` với `Io` của vỏ); `desk:*` / `shell:*` lạ không tới desk; kênh desk chưa có → `not ported: <channel>`.

## core-desk trong vỏ (`desk.rs`, `hosts.rs`, `desk_text.rs`) — T1
- Link thẳng crate `core-desk` (path). `desk::boot` trước `Serve::start`: `Desk::standard(env_for(data_dir, CARGO_PKG_VERSION))` + `desk:backup-apply-pending` (thay `backups.applyPending()` lúc boot của Electron). `DeskEnv::from_env` rồi đè `data_dir`, `app_version` (trừ khi có `CCM_APP_VERSION`).
- `Io::emit` → `emit_to(main)` + `compact` nếu có. `Io::host` → `hosts::call`: `backup.readLocal` (`eval_with_callback` `LOCAL_SNAPSHOT_JS` trên webview gọi, max 3 s), `backup.github` / `buildClean.running` / `buildClean.daemons` → `[]` (chờ D2 GitHub, resources, run), `backup.saveDialog` / `openDialog` (dialog plugin, filter json; `CCM_E2E_BACKUP_FILE` thay dialog), `backup.confirmApply` / `buildClean.confirm` (câu en/vi ở `desk_text.rs` giống `strings.ts`; message dialog `OkCancelCustom`; `buildClean.confirm` trả 0 / 1 như `showMessageBox`), `backup.relaunch` (quitting + shutdown + `app.restart()`, sau 200 ms), `buildClean.trash` (crate `trash`, chỉ path tuyệt đối). ## Child webview (`guest.rs`, `guest_ipc.rs`, `guest.js`, `webview.js`, `native.rs`, `capture.rs`, `shot.rs`) — T1
- Trang: `webview.js` vá `Document.prototype.createElement('webview')` → gắn API WebviewTag (`loadURL`, `getURL`, `getTitle`, `canGoBack/Forward`, `goBack/Forward`, `reload`, `reloadIgnoringCache`, `stop`, `setZoomFactor`, `executeJavaScript`, `getWebContentsId`, `capturePage`, `openDevTools/closeDevTools/isDevToolsOpened`, `focus`, thuộc tính `src`) + CSS `webview { display: flex }`. Mở child khi element đã gắn DOM (`shell:guest open` → id). Bám vị trí: `getBoundingClientRect` + `scale = rect.width / offsetWidth` (khung thiết bị dùng `transform: scale`), gửi `bounds` khi đổi; tick rAF 450 ms sau `resize/scroll/pointer/click/key/wheel` (900 ms sau transition / animation) + `setInterval` 250 ms khi còn child. Ẩn child khi element không hiện (`checkVisibility`, size 0) hoặc bị overlay che: `[role=dialog|alertdialog|menu|tooltip]`, `[data-context-menu]`, con trực tiếp của `body` (trừ `#app`); overlay chứa chính element thì bỏ qua. Element rời DOM → ẩn, quá 3 s → đóng child (gắn lại → mở lại URL cũ). Event `shell:guest` → `did-start-loading`, `did-navigate`, `dom-ready`, `did-finish-load`, `did-stop-loading`, `did-navigate-in-page`, `page-title-updated`, `console-message`, `page-favicon-updated`; event đến trước khi `open` trả id được giữ (`early`) rồi phát.
- Rust `guest.rs`: label `guest-<n>`, `WebviewBuilder` chung `data_directory` với cửa sổ chính (CDP thấy; mất cô lập `persist:ccm-preview`, plan §3.4), `initialization_script(guest.js)`, `devtools(true)` (feature `devtools`), `on_navigation` chỉ http(s) và không phải origin app, `on_new_window` loopback → điều hướng chính child, web khác → trình duyệt ngoài, luôn Deny (như `hardenGuest`). `on_page_load` Started → `start` + huỷ các `exec` đang chờ; Finished → `finish` + `canBack/canForward` (`native::history`). `on_document_title_changed` → `title`. Vị trí logic = CSS px × zoom trang; zoom child = `setZoomFactor × scale × zoom trang`. Op chỉ cho cửa sổ sở hữu child. `exec`: bọc `Promise.resolve((code))` gửi `__ccmGuestReply(nonce, ok, v)` (chạy qua `eval_with_callback`; wrapper trả `true` thì chờ reply max 10 phút; reply chỉ nhận từ đúng child). `back/forward/stop/reload` = `history.back()` / `window.stop()` / `location.reload()`.
- `guest.js` (child, main frame): `__ccmGuestReply` (không ghi đè được), `pushState/replaceState/popstate/hashchange` → `nav`, `console.error/warn` + `error` + `unhandledrejection` → `console` (max 50 / s, 4000 ký tự), favicon, phím: `workspaceChord` (port từ `preview/keys.ts`, giữ đồng bộ) → `key` → `ccm:forward-key` tới cửa sổ chủ; F5 / Ctrl·⌘+R reload, F12 devtools.
- Command `guest(kind, data)` (`guest_ipc.rs`): capability `guest` chỉ cho webview `guest-*` trên remote `http(s)://*(:*)`, quyền `allow-guest` (không có `core:default`, không gọi được `ccm`). Kiểm label → id → chủ; console chỉ `error`/`warning`, source http(s); favicon http(s) ≤ 8; chord phải có Ctrl/Alt/⌘, key/code ≤ 32 ký tự.
- Chụp: `native::capture` = WebView2 `CapturePreview` PNG (handler async trong `with_webview`, chờ max 20 s) / mac `takeSnapshotWithConfiguration` → TIFF → `NSBitmapImageRep` PNG (chưa biên dịch trên mac). `ccm:capture-guest` (child của chính cửa sổ) → clipboard (`arboard`, RGBA từ crate `image`). `ccm:capture-rect` (dust) = chụp webview chính, cắt `rect × zoom × px/dip`, thu về `dust_size` (≤ 160k px, ≤ kích thước DIP) như `capture.ts`, max 4 Mpx. `ccm:clipboard-image` (data URL PNG ≤ 20 MB, đúng chữ ký) / `-file` (tuyệt đối, png/jpg/gif/webp ≤ 20 MB) → giải mã rồi ghi clipboard.

## Terminal (`pty.rs`, `presets.rs`)
- Spawn binary `orrery-core` (chế độ pty, stdin/stdout NDJSON như `pty/supervisor.ts` `RustHost`), env chỉ `CORE_ENV_KEYS`, stderr → `<data>/pty.log`, `CREATE_NO_WINDOW`. Lý do không link thẳng `core-pty`: `server::run` dùng stdin/stdout của process (serve đã giữ stdin), `serve()` private, `adopt_self` đưa cả process vào job object (sẽ kéo WebView2 theo), crash pty không làm sập app; giống đường Electron đã có E2E.
- `init` {token 32 byte, origins [app origin], appVersion} → chờ `listening` (max 10 s) → endpoint `ws://127.0.0.1:<p>/pty` + subprotocol `ccm.pty.<token>`. Thread `pty-control` trả: `resolve` (preset claude / codex / shell, deepseek tắt; cwd tuyệt đối, có thật, không UNC, bỏ `\\?\`; max 16 pane sống; `resume` / `session` chỉ UUID) → `resolved` với `child_env` (bỏ `CCM_*`, `ORRERY_*`, `ELECTRON_*`, `WEBVIEW2_*`, `NODE_OPTIONS`, biến session agent; thêm TERM / COLORTERM / FORCE_HYPERLINK); `cwd` → `cwd-ok` (bỏ thư mục gốc ổ); `wt` → `wt.error git` (chưa port); `exited` / `removed` cập nhật đếm.
- `presets.rs`: Windows = `powershell.exe` tuyệt đối dưới `SystemRoot`, `-NoLogo -NoExit -EncodedCommand` (UTF-16LE base64) với `PS_CWD_HOOK` (OSC 9;9) + lệnh agent; posix = `$SHELL` an toàn hoặc `/bin/zsh`/`/bin/bash`, bash có `PROMPT_COMMAND` OSC 7. Chưa có: MCP `orrery` (D8), shim claude/codex, shell integration OSC 633, zsh ZDOTDIR wrapper, nhánh git của pane.

## Deep link (`links.rs`)
- `parse`: `agent-monitor://open?agent&cwd&resume` (như `openLink.ts`), `focus?k&t`, `snooze?…`. `handle` chạy trên thread: open → max 10 link / phút, `show_main`, kiểm thư mục, hỏi trang `ccm:orrery` {action `session.open`, caller `url`} (max 5 s) → lỗi khác `setup` hiện dialog; focus → hỏi trang `ccm:focus` (max 1,5 s) rồi `POST /focus`, không được thì `ccm:select`; snooze → `GET /snooze`. Dev không đăng ký scheme (chỉ argv của instance thứ hai).
