# shell — Tauri vỏ `apps/shell` (PLAN-v87 bước 6b, WP T0 + T1 + T2)

Cargo workspace riêng (`[workspace]` trống, `Cargo.lock` riêng, target `apps/shell/target`), không nằm trong workspace `apps/core`; link `core-serve` qua path. Tauri `=2.12.5` (feature `tray-icon`, `unstable`), `tauri-build =2.7.4`; plugin `single-instance` (+`deep-link`), `deep-link`, `autostart`, `notification`, `dialog`, `opener`. Binary `orrery-shell`; `windows_subsystem = "windows"` chỉ ở release.

## Khởi động (`main.rs`)
1. `config.rs` `ShellConfig::from_env`: key ngẫu nhiên 32 byte hex (`random_hex`, getrandom), cổng = `CCM_PORT` (0 = cổng trống); bản debug không có `CCM_PORT` → **4419**, không có `CCM_DATA_DIR` → `%TEMP%/orrery-shell-dev` (dev không bao giờ đụng 4317 / `%LOCALAPPDATA%\ccm`). `CCM_WEB_DIST` → `<exe>/web` → `apps/web/dist`. `CCM_CORE_BIN` → `<exe>/orrery-core(.exe)` → `apps/core/target/release/orrery-core(.exe)`. WebView2 profile = `CCM_SHELL_WEBVIEW_DIR` hoặc `<data>/shell-webview`. `ServeConfig::from_vars` với các giá trị đè (`CCM_APP_KEY`, `CCM_PORT`, `CCM_WEB_DIST`, data dir dev, `CCM_STATUSLINE_COMMAND` rỗng nếu chưa đặt), `CCM_HOST_RPC` luôn tắt (SystemDeps, không toast từ serve).
2. `serve.rs` `Serve::start`: `/health` đã trả lời trước khi chạy → `PortInUse` (không chạm app khác); `stdio::take_stdin()` thay stdin của process bằng pipe của mình (Windows `CreatePipe` + `SetStdHandle`, macOS `pipe` + `dup2`) vì `core_serve::run` đọc lệnh điều khiển từ stdin và EOF = tắt; chạy `core_serve::run(cfg)` trên thread `core-serve`; chờ `/health` (max 30 s), thread thoát mã 3 = cổng bận. `stop()` ghi `{"type":"shutdown"}` vào pipe, chờ max 4 s. `request()` = HTTP/1.1 tối giản (std `TcpStream`) cho `/health`, `/focus`, `/snooze` có header `x-ccm-app`.
3. Lỗi khởi động → `fail()` hiện dialog lỗi (strings vi/en) rồi thoát 1.
4. Tauri builder: single-instance (argv có `agent-monitor://` → `links::handle`, không thì hiện cửa sổ), deep-link `on_open_url` (macOS), autostart (`--hidden`), notification, dialog, opener; `manage(Shell)`; command duy nhất `ccm`; `on_window_event` → `window::on_window_event`. `setup`: `capability()` thêm lúc chạy capability `app` cho remote `http://127.0.0.1:<port>/*`, cửa sổ `main` + `compact`, quyền `core:default`, `start-dragging`, `internal-toggle-maximize`, `allow-ccm` (AppManifest trong `build.rs`). `ExitRequested` không mã → giữ app (tray); `Exit` → `Shell::shutdown` (pty rồi serve, một lần).

## Cửa sổ (`window.rs`, `header.js`)
- `create_main`: URL `http://127.0.0.1:<port>/?k=<key>` → core-http đổi sang cookie (`core-http/src/cookie.rs`), redirect `/`. Windows `decorations(false)` + `shadow(true)` (giữ `THICKFRAME` / `MAXIMIZEBOX`, snap phím chạy), macOS `TitleBarStyle::Overlay` + `hidden_title`. Nền theo `shell-appearance.json`. `on_navigation`: chỉ origin app (khác → trình duyệt ngoài, chặn); `on_new_window`: URL app → cửa sổ `compact`, còn lại → trình duyệt ngoài, luôn `Deny`. `on_page_load` Finished → `set_zoom(1.2^level)`. Vị trí / kích thước / maximize lưu khi đóng, chỉ phục hồi nếu còn nằm trên một màn hình.
- Close cửa sổ `main` → ẩn vào tray (lần đầu Windows: notification `hidden_notice`), trừ khi đang `quitting`.
- `init_script(origin)`: `(function(){const __ccmShell={platform, origin, sync:{ccm:core-serve:'rust', ccm:deepseek-enabled:false}}; if (location.origin!==origin) return; shim.js; header.js; webview.js})()` → chỉ trang app có `window.ccmDesktop`. Mỗi phần kết thúc bằng `;` (header.js kết thúc `})()`, thiếu `;` thì IIFE sau bị gọi như tham số → webview.js không chạy; test `the_init_script_ends_every_part_with_a_semicolon`).
- `on_permission_request`: trang app xin `ClipboardRead` → Allow (WebView2 mặc định hỏi; E2E agent-map đọc clipboard bằng `navigator.clipboard.readText`). `on_page_load` Started của `main` / `compact` → `guest::close_owned` (trang tải lại thì đóng hết child cũ). `set_zoom_all` → `guest::refresh_all` (vị trí child = CSS px × zoom trang).
- `header.js`: CSS chừa 138 px bên phải header (`header.ccm-titlebar[data-title-bar] > div`), nút min / max-restore / close tự vẽ (Windows, màu `--ccm-ink`, close hover `#c42b1c`) gọi `shell:window`; gắn `data-tauri-drag-region` lên header + phần tử không tương tác bên trong (MutationObserver chỉ trên header sau khi tìm thấy); Ctrl/⌘ `=`/`+`/`-`/`0` → `ccm:zoom` (như `before-input-event` của Electron).
- `tray.rs`: menu Mở dashboard / Cửa sổ gọn / Chạy cùng Windows (checkbox, chỉ bản release) / Mở thư mục log (= data dir) / Thoát; click trái = hiện cửa sổ. `quit()` lưu bounds, `shutdown`, `exit(0)` trên thread riêng.

## Child webview (`guest.rs`, `guest_ipc.rs`, `guest.js`, `webview.js`, `native.rs`, `capture.rs`, `shot.rs`) — T1

## Terminal (`pty.rs`, `presets.rs`)
- Spawn binary `orrery-core` (chế độ pty, stdin/stdout NDJSON như `pty/supervisor.ts` `RustHost`), env chỉ `CORE_ENV_KEYS`, stderr → `<data>/pty.log`, `CREATE_NO_WINDOW`. Lý do không link thẳng `core-pty`: `server::run` dùng stdin/stdout của process (serve đã giữ stdin), `serve()` private, `adopt_self` đưa cả process vào job object (sẽ kéo WebView2 theo), crash pty không làm sập app; giống đường Electron đã có E2E.
- `init` {token 32 byte, origins [app origin], appVersion} → chờ `listening` (max 10 s) → endpoint `ws://127.0.0.1:<p>/pty` + subprotocol `ccm.pty.<token>`. Thread `pty-control` trả: `resolve` (preset claude / codex / shell, deepseek tắt; cwd tuyệt đối, có thật, không UNC, bỏ `\\?\`; max 16 pane sống; `resume` / `session` chỉ UUID) → `resolved` với `child_env` (bỏ `CCM_*`, `ORRERY_*`, `ELECTRON_*`, `WEBVIEW2_*`, `NODE_OPTIONS`, biến session agent; thêm TERM / COLORTERM / FORCE_HYPERLINK); `cwd` → `cwd-ok` (bỏ thư mục gốc ổ); `wt` → thread `pty-worktree` chạy `worktree::answer` (port `answerWorktree`: `wt.list|add|remove`, mã lỗi noGit / notRepo / branch / exists / dirty / main / busy / unknown / git; 1 thay đổi tại 1 lúc `BUSY`; remove chặn khi pane chưa exit có `cwd` / `liveCwd` nằm trong worktree; dest `<repo>-wt/<branch, / → ->`; `wtcopy.rs` = `copySetupFiles`: max 1 MB / file, 5 MB tổng, sâu 4, không ghi đè); `Panes.dirs` giữ cwd / liveCwd / exited mỗi pane; `exited` / `removed` cập nhật đếm.
- `presets.rs`: Windows = `powershell.exe` tuyệt đối dưới `SystemRoot`, `-NoLogo -NoExit -EncodedCommand` (UTF-16LE base64) với `PS_CWD_HOOK` (OSC 9;9) + lệnh agent; posix = `$SHELL` an toàn hoặc `/bin/zsh`/`/bin/bash`, bash có `PROMPT_COMMAND` OSC 7. `preset_command_with(…, AgentOpts{mcp, name})` = cờ MCP như `presets.ts` (claude `--mcp-config $ORRERY_MCP_CONFIG`, codex `-c mcp_servers.orrery.url=$ORRERY_API/mcp` + `bearer_token_env_var`, `-n '<name>'` chỉ claude mới). Shim (`shim.rs`, port `shim.ts` 1:1): spawn shell có `shim:true` + MCP config → ghi `<data>/shell-shim/{claude,codex}[.cmd]`, PATH đặt shim dir đầu + `ORRERY_SHIM_DIR` (`apply_shim_env`), Windows thêm `PS_SHIM_FIRST` vào script PowerShell, zsh dùng wrapper `<data>/shell-init-tauri/.z*` (ZDOTDIR + `AGENT_MONITOR_ZDOTDIR`; đưa shim lên đầu sau `.zshrc` + OSC 7). Chưa có: shell integration OSC 633 (nonce), bash `--init-file` re-prepend shim (bash profile đặt lại PATH thì mất shim), nhánh git của pane.
