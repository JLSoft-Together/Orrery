# apps/pwa (@ccm/pwa) — iPhone / iPad web app (v98 WP-54)

- Build: Vite base `/app/`, dist -> relay `/app/*`. `vite/serviceWorker.ts` writes `sw.js` (precache list + cache name from content hash; skip-waiting only on message; `push` / `notificationclick` delegate to `self.orreryPush`, WP-56). `vite.config.ts` `__DEV_TOOLS__` (serve only) gates Eruda + dev log (`vite/devLog.ts`).
- wasm: `npm run wasm -w @ccm/pwa` -> `src/gen/` (gitignored), `scripts/{build-wasm,ensure-wasm}.mjs`.
- `src/remote/`: `noise.ts` (NoiseSuite / NoiseLink over core-remote-wasm, frees wasm objects), `wire.ts` (WireSocket), `session.ts` (RemoteSession: request/event/keepalive), `dialer.ts` (planRoutes, dial), `handshake.ts`, `connection.ts` (MachineConnection: backoff, background/foreground, 4401 -> onRevoked), `pairing.ts` (PairFlow, QR v1/v2 candidates), `jsonPatch.ts`, `monitorReducer.ts`, `machineData.ts` (per-machine view, cache debounce), `hub.ts` (RemoteHub: machines + connections + wipe).
- `src/storage/`: `idb.ts` (Db), `keyStore.ts` (AES-GCM wrapped key, `Unlocker` hook for WebAuthn), `repos.ts` (MachineRepo, IdbSnapshotCache; tombstones stop late saves after forget).
- `src/stores/`: Pinia `hub` (mirrors hub events), `update`. `src/update/`: version.json check, SW registration.
- E2E: `npm run e2e -w @ccm/pwa` (`e2e/run.mjs`, `e2e/peer` Rust fake desktop copied from the spike peer + snapshot/events/patch/revoke stdin commands).

- Views: `HomeView` (cards, duplicates + clean, FAB, empty), `PairView` (+ `components/QrScanner.vue`, jsQR via `lib/qrDecode.ts`, paste via `lib/qrInput.ts`), `MonitorView` (A cards + filters, B groups, `prefs.monitorMode`), `SessionView`, `SettingsView` (+ `SettingsMachines`, `Toggle`), `LockView`, `DebugView` (log only).
- Pure logic `src/lib/`: `machineGroups`, `monitorModel` (parse snapshot, filter, group, activity), `qrInput`, `lockPolicy`, `appearance`, `confirm`.
- Prefs: `storage/localPrefs.ts` (localStorage: language, theme, monitor mode, lock, credential id, last machine), `storage/notifyPrefs.ts` (IndexedDB kv: 3 groups + content + bells; `stores/prefs.ts` emits `events` bell / notify for WP-56). Lock: `security/webauthn.ts`, `stores/lock.ts`; `main.ts` delays `hub.start` until unlocked so the IndexedDB snapshot cache is not read while locked.
- E2E: `e2e/lib/{ctx,ui-steps,shots,lock-step,y4m}.mjs`; 19 steps per browser; Chromium scans a QR from a fake y4m camera and uses a CDP virtual authenticator.

## WP-56a (Web Push)
- `public/push-sw.js`: SW push riêng mỗi máy (`/app/push-sw.js`, scope `/app/push/<machineId>/`, không precache — `vite/serviceWorker.ts` SKIP): `push` → `showNotification(title, {body, tag, data:{url}})`, bỏ khi có cửa sổ focus + visible (WebKit hiện rồi đóng); `notificationclick` → `postMessage {type:'orrery-open', url}` + focus, hoặc `openWindow`. Vì sao riêng: 1 subscription = 1 `applicationServerKey`, mỗi máy có khoá VAPID riêng.
- `src/push/webPush.ts`: `pushSupport` (iOS cần standalone), `validKey`, `muteFor` (chuông tắt = 3 nhóm), `registerFields`, `ensureSubscription` / `dropSubscription` (`PushBrowser` để test; `find` kiểm đúng scope, không đụng SW chính).
- `src/stores/push.ts`: `enable` (xin quyền chỉ ở đây, từ nút) / `disable` (`push.unregister`), `sync(machine)` khi nhận `webpush.config` (`hub.onDevice`), khi bell / nhóm / content đổi (`prefs.events`), quên máy → drop; `openFromWorker` điều hướng deep link. `remote/hub.ts` giữ `pushKey(machine)` (DEVICE_EVENTS có `webpush.`). `notifyPrefs.ts` thêm `push` (opt-in), `content` mặc định `true`.
- UI: `SettingsView` dòng `push-row` (`data-state` unsupported|install|denied|off|on, icon + chữ + màu). Test `src/push/push.test.ts` (helpers, store, SW chạy trong `new Function` với `self` giả). E2E `e2e/lib/push-steps.mjs` (2 bước / browser, peer gửi `webpush.config` + in `push.register`; Chromium: PushManager giả qua init script, CDP `ServiceWorker.deliverPushMessage`; ảnh → `docs/qa/v98/WP-56a`).
