# Release 4.0.3 (2026-11-12)

## English

**Fixes**
- macOS: dragging files and folders from Finder into a terminal pane works again: Claude / Codex panes get `@path`, shell panes get the quoted path. Names with spaces or Vietnamese accents keep the right path.
- macOS: dragging rows from the Explorer panel into a terminal pane works again.

## Tiếng Việt

**Sửa**
- macOS: kéo file / thư mục từ Finder vào pane terminal chạy lại: pane Claude / Codex ra `@path`, pane shell ra path có quote. Tên có dấu cách hoặc tiếng Việt có dấu vẫn đúng path.
- macOS: kéo dòng từ panel Explorer vào pane terminal chạy lại.
