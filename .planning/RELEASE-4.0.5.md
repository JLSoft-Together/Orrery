# Release 4.0.5 (2026-11-13)

## English

**New**
- Workspace project groups (Chrome tab-group style): one tab can hold several projects side by side, each in its own group with a coloured header; split 1–2–3 sessions inside a group, new sessions always open in that group's project. Add a project with Split → **Other project…**, the folder+ button on a group header, **Ctrl+Alt+G**, or by dragging a project from the sidebar onto a pane. Drag a group header to reorder, drop it on the tab strip to make its own tab; right-click for rename, colour, collapse, new session, move to new tab, close. **Ctrl+Alt+←/→** moves focus between groups, **Ctrl+Alt+Shift+←/→** moves the group. Saved layouts keep the groups. Single-project tabs are unchanged.
- Sidebar: Ctrl/⌘+click, Shift+click or Shift+↑/↓ select several sessions; right-click → **Group into one tab**, **Ungroup**, **Close N sessions**. A tab with several projects shows as one entry with a sub-list per project.
- Galaxy theme: a second layer of bigger stars that twinkle, and meteors across the background, panels and terminals (behind the text). Settings → Appearance → **Star effect**: Off / Twinkle / Twinkle + meteors. Reduce Motion turns it off.

**Fixes**
- In-app notifications (agent finished, break reminder, command done) were blocked on Windows by the app's permission list.
- Images pasted into a session (Alt+V or Ctrl+V) showed in Attachments without a preview.

## Tiếng Việt

**Mới**
- Nhóm project trong Workspace (kiểu tab group của Chrome): một tab chứa nhiều project nằm cạnh nhau, mỗi project một khối có header màu riêng; trong khối chia 1–2–3 session tuỳ ý, session mới luôn mở trong project của khối đó. Thêm project bằng Split → **Project khác…**, nút thư mục+ trên header khối, **Ctrl+Alt+G**, hoặc kéo project từ sidebar thả vào pane. Kéo header để đổi thứ tự, thả lên dải tab để tách thành tab riêng; chuột phải để đổi tên, đổi màu, thu gọn, mở session mới, tách ra tab, đóng khối. **Ctrl+Alt+←/→** chuyển sang khối bên cạnh, **Ctrl+Alt+Shift+←/→** đổi thứ tự khối. Layout đã lưu giữ nguyên các khối. Tab chỉ có 1 project không đổi.
- Sidebar: Ctrl/⌘+click, Shift+click hoặc Shift+↑/↓ để chọn nhiều session; chuột phải → **Group vào một tab**, **Ungroup**, **Đóng N session**. Tab có nhiều project hiện thành một mục, bên trong chia theo từng project.
- Theme Ngân hà: thêm lớp sao to nhấp nháy và sao băng chạy qua nền, panel và terminal (nằm sau chữ). Settings → Giao diện → **Hiệu ứng sao**: Tắt / Nhấp nháy / Nhấp nháy + sao băng. Bật Reduce Motion của hệ thống thì tắt hiệu ứng.

**Sửa lỗi**
- Thông báo trong app (agent xong việc, nhắc nghỉ, lệnh chạy xong) bị danh sách quyền của app chặn trên Windows.
- Ảnh paste vào session (Alt+V hoặc Ctrl+V) hiện trong Attachments nhưng không có preview.
