# RELEASE 4.0.7

Release 2026-11-16 (tag v4.0.7): hot fix UI mới Sương kính và nút cửa sổ.

## Tiếng Việt

### Nút cửa sổ
- Nút thu nhỏ, phóng to, đóng cửa sổ nhỏ gọn (28px), theo màu theme; rê vào nút đóng thì nền đỏ.
- Áp dụng cho cả giao diện cũ, giao diện mới và màn khởi động.

### Giao diện mới (Sương kính)
- Nút đóng cửa sổ không còn đè lên thanh tab; dải trên cùng dùng để kéo cửa sổ.
- Nút + trên rail session để mở thư mục project mới.
- Menu + trên thanh tab và các menu mở từ rail hiện trên terminal, mờ kính đúng, không bị cắt.
- Hạn mức và trạng thái mở lên trên, hiện đủ nội dung, không bị cắt ở cạnh rail.
- Khoảng cách 12px đều nhau quanh rail, thanh tab và pane (trước đây chỗ 12px, chỗ 28px).

### Header pane
- Nút Đính kèm (kèm số file) và MCP & plugin nằm ngay cạnh branch git, bấm 1 lần là mở, không phải vào menu `…`.

## English

### Window buttons
- Smaller minimize, maximize and close buttons (28px) that follow the theme; close turns red on hover.
- Used by the classic UI, the new UI and the startup screen.

### New UI (Mist)
- The close button no longer sits on the tab bar; the top strip drags the window.
- A + button in the session rail opens a project folder.
- The tab bar + menu and menus opened from the rail show above terminals, blurred and uncut.
- Limits and status opens upward in full instead of being cut off at the rail edge.
- The same 12px spacing around the rail, tab bar and panes (was 12px in some places, 28px in others).

### Pane header
- Attachments (with a file count) and MCP & plugins sit next to the git branch, one click instead of the `…` menu.
