## Office
- Theme packs and a new 3D office style (beta).
- Full screen fills the whole screen with the office.
- The office draws much less per frame, idles at 30 fps and lightens itself on slow GPUs.

## Workspace
- Restore a workspace with only the projects you pick running; restored sessions start two at a time.
- VS Code style auto save in the file editor (off by default: after a delay, on focus change or on window change).
- HTML files render in the file viewer like Markdown.
- Atom Material icons for file panes and project folders.

## Monitor
- The header now sits in the window title bar.
- The session bar, activity panel and timeline view are gone; the Sessions panel starts hidden.
- The agent map is lighter: fewer forced reflows, no endless motion, and no token +N badge on nodes.

## Fixes
- Resizing a terminal pane no longer duplicates the shell prompt.
- Dropping a file no longer opens the attachment tray.
- The terminal scrollbar uses the pane's right padding.
