## WP-111a: G1 nền Rust: GitHub API ghi, PR, CI, theo dõi CI
- Đọc trước: `RULES-v111.md`, `SPEC-v111-git-preview.md` mục G1 (phần Rust), skill rust-conventions.
- Mục tiêu: core có đủ API cho PR + CI + merge, chưa làm UI.
  - `core-desk/src/github/api.rs`: `send(method, base, token, route, body, timeout)` POST/PUT/PATCH/DELETE; đọc body cả 4xx (lấy `message`, che token); dùng chung 1 ureq Agent (OnceLock); giữ `get` cũ chạy như cũ.
  - `github/pulls.rs` mới: `find_pr(owner, repo, head)`, `create_pr {base, head, title, body}` (PR thường), `merge_pr {number, method merge|squash|rebase, sha}`, `delete_ref heads/<branch>`, `default_branch(owner, repo)`, `remote_branches` (cho chọn base).
  - `github/ci.rs` mới: `ci_status(owner, repo, sha)` gộp check-runs + combined status → `{state: pending|success|failure|neutral|none, runs:[{name,state,url,jobId,startedAt,completedAt}]}`; `job_log_tail(jobId, 60)` (redirect, max 2 MB, che secret bằng `core-transcript` `mask_secrets`).
  - `github/ci_watch.rs`: watch {root, branch, sha, pr?}; mỗi 30s, max 60 phút, dừng khi mọi run xong; chạy cả khi app ở nền; max 8 watch; không trùng. Xong → event `ci.done {root, branch, pr?, state, failed:[names], url}` qua kênh event sẵn có của desk (xem cách các module khác phát event tới web + Telegram + push điện thoại; nối Telegram (nút Mở PR) và push điện thoại theo luật rời máy N phút, che secret, cắt 120 ký tự).
  - IPC: `ccm:gh-pr` op find|create|merge|deleteBranch|base, `ccm:gh-ci` op status|log|watch|unwatch. Mọi op `resolve(ctx, root, remote)` lấy account; access none → lỗi `gh.noAccess`; 403 thiếu quyền → lỗi `gh.scope` kèm tên quyền. Merge và xoá nhánh đi qua native confirm (`preview/gate.rs` confirm) liệt kê `#N -> base (method), xoá nhánh x`.
  - Push từ Orrery xong (hook vào chỗ push hiện có) → tự đăng ký watch nhánh đó.
- Phạm vi: `apps/core/crates/core-desk/src/github/**`, chỗ đăng ký IPC của core-desk, chỗ push git trong core-desk (chỉ thêm gọi watch), Telegram / push phone chỉ thêm 1 loại thông báo. Chủ hot file lượt này: `packages/shared/src/types.ts` (event `ci.done`, kiểu PR/CI), `apps/web/src/core/lib/preview.ts` (wrapper `ghPr`, `ghCi` + kiểu trả).
- Cấm đụng: web components (WP-111f làm UI).
- Model: opus (token, network, tác vụ nền). Song song: 111b, 112f.
