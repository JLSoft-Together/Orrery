## WP-111d: G2 Worktree tự setup và tự dọn
- Đọc trước: `RULES-v111.md`, `SPEC-v111-git-preview.md` mục G2.
- Chủ nhân chốt: cấu hình ở `.orrery/worktree.json` trong repo chính; setup chạy trong pane shell mới của tab worktree; dọn hỏi Xoá / Giữ sau merge.
- Nền: `apps/shell/src/worktree.rs` (`add` :122, `remove` :150), `apps/shell/src/wtcopy.rs:72` `copy_setup_files` (mặc định `.env*`, `**/google-services.json`), `core-desk/src/preview/worktrees.rs` `merge_branch(.., keep)`, `preview/exec.rs` ExecOpts timeout + kill_tree, web `features/git/components/WorktreeMenu.vue`, `core/lib/preview.ts:310` `wtMerge`.
- Mục tiêu:
  - Đọc `.orrery/worktree.json` `{copy?: string[], setup?: string[], cleanup?: string[]}` (sai kiểu → bỏ qua field, báo lỗi nhẹ). Không có file → giữ copy mặc định, không setup.
  - Tạo worktree: copy theo `copy`; có `setup` → native confirm lần đầu cho mỗi repo và mỗi khi nội dung `setup` đổi (lưu hash đã duyệt trong data dir), rồi web mở pane shell mới trong tab worktree và gõ + chạy các lệnh nối `&&` (PowerShell: `;` + `if ($?)`), dùng prefill submit có sẵn của pane shell (pane shell không phải agent nên được submit).
  - Nút "Tạo .orrery/worktree.json từ gợi ý" trong WorktreeMenu: đoán theo lockfile (`package-lock.json` → npm ci/install, `pnpm-lock.yaml` → pnpm install, `yarn.lock` → yarn, `bun.lockb` → bun install, `pubspec.yaml` → flutter pub get); ghi file (confirm nếu đã có), mở trong editor pane; không tự commit.
  - Dọn: sau `wtMerge` thành công không `kept` → hộp hỏi "Xoá worktree + nhánh <x>?" (Xoá / Giữ). Xoá: chạy `cleanup` (timeout 120 s, kill tree) trong thư mục worktree, đóng pane thuộc worktree, `git worktree remove`, `git branch -d` (không `-D`; chưa merge → báo, không xoá). Worktree còn thay đổi chưa commit → không xoá, báo. Xuất hàm web `askCleanupWorktree(root, branch)` để WP-111f gọi sau merge PR.
- Phạm vi: `apps/shell/src/worktree.rs`, `wtcopy.rs`, chỗ IPC worktree của shell, `core-desk/src/preview/worktrees.rs` + `ipc_wt.rs`, `features/git/components/Worktree*.vue`, `features/git/lib/*` mới, i18n git. KHÔNG sửa `workspace.ts` / `TermPane.vue` (của 111c lượt này): mở pane shell bằng API công khai có sẵn của store; thiếu API thì ghi "Hot file cần thêm".
