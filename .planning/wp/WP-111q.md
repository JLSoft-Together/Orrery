- Việc:

  3. E2E mới của đợt: `window-restore`, `v111-rail-filter`, `v111-export`, `v111-preview`, `v111-send-selection`, `run-pane`, `v111-wt`, `v111-checklist`, `wp112e-notify`, `v111-pr`, `v111-pick`, `v112b-first-run`, `v111-commit-chat`, `v112-header`, `v112d-launch-template`, E2E của 112h / 112g / 112c. Sau đó `npm run e2e -w @ccm/shell` (toàn bộ) và liệt kê fail; fail cũ có sẵn trước đợt (kiểm bằng `git stash` KHÔNG được dùng: so với báo cáo cũ / chạy lại riêng lẻ) ghi riêng.
  4. Kiểm tích hợp còn treo: (a) mẫu khởi chạy 112d ra đúng cờ CLI thật (fake `claude` / `codex` trên PATH in argv ra file, mở pane bằng mẫu, đọc argv); (b) chip dev server mất sau Ctrl+C (112h); (c) toast + chip CI toàn cục (App.vue `useCiEvents`); (d) i18n snapshot khớp; (e) `qa-fast.mjs` E2E_MAP có các E2E mới (thêm map cho file của đợt).
  5. Chụp ảnh tổng quan desktop UI next (rail, header, footer, Git Log có PR + chip) vào `docs/qa/v111/QA/`, ghi `docs/qa/v111/QA/RESULT.md` (ĐẠT / LỖI từng mục).
  6. Sau E2E: `git status` liệt kê ảnh `docs/qa/<cũ>` bị ghi đè (không tự restore, main làm).
