## WP-113c: F2 desktop (cài APK qua adb, mở app kèm mã ghép đôi, adb reverse, đọc version)
- Mục tiêu: core-desk có op cài APK lên máy adb, mở app Orrery Remote kèm extra `pairQr`, `adb reverse`, đọc versionName của package; kênh `ccm:*` + type web + shim.
- Spec item: SPEC-v113 §F2 phần "Làm (desktop)" mục 1-6 (đọc `.planning/SPEC-v113-phone-devices.md`).
- Phạm vi file: `apps/core/crates/core-desk/src/devices/install.rs` (mới, chứa logic), `devices/mod.rs` (khai báo module), `devices/ipc.rs` hoặc `ipc_ext.rs` (đăng ký kênh), `devices/manager.rs` CHỈ thêm ≤ ~10 dòng gọi sang (file đã 537 dòng), `run/parse.rs` (chỉ khi cần public hoá `install_failure`), test mới `devices/install_tests.rs`; `apps/web/src/core/lib/desktop.ts` (type kênh), `scripts/gen-desk-shim.mjs` (nếu kênh cần khai báo ở đây), `apps/web/src/features/devices/lib/devices.ts` (wrapper gọi kênh) + test.
- Cấm đụng: `apps/shell/src/remote/*` (WP-113a), `apps/mobile/*` (WP-113a, 113d), `packages/shared/src/types.ts`, i18n, hành vi Run hiện có (không đổi kết quả `AndroidRunner::install`).
- Phụ thuộc: không | Song song với: WP-113a, WP-113d | Worktree: không
- Skill: `rust-conventions`.
- Model: sonnet.
- Làm:
  1. `install(id, apk_path) -> Value {ok, error?, detail?}`: `adb -s <id> install -r -t <apk>` timeout 120s; map lỗi: `restricted` (INSTALL_FAILED_USER_RESTRICTED), `storage` (INSUFFICIENT_STORAGE), `signature` (UPDATE_INCOMPATIBLE / signatures do not match), `downgrade` (VERSION_DOWNGRADE), `abi` (NO_MATCHING_ABIS), `offline`, `unauthorized`, `timeout`, `other`. Dùng lại `install_failure` ở `run/parse.rs` (~229-255) nếu khớp, không nhân bản. KHÔNG tự gỡ app. Kiểm `is_id(id)`, apk là file `.apk` tồn tại, đường dẫn tuyệt đối.
  2. `open_pair(id, qr_text)`: `am start -n dev.ccm.orrery.remote/.MainActivity --es pairQr <qr>` qua `sh_quote` (`toggles.rs`); qr ≤ 640 byte, chỉ ký tự in được, từ chối khác.
  3. `reverse(id, port, on)`: `adb -s id reverse tcp:P tcp:P` / `--remove tcp:P`; port 1-65535.
  4. `package_version(id, package)`: `dumpsys package <pkg>` parse `versionName=` và `versionCode=`; package hợp lệ (regex java package).
  5. Kênh: `ccm:dev-install`, `ccm:dev-open-pair`, `ccm:dev-reverse`, `ccm:dev-pkg-version`, đăng ký cùng chỗ `ccm:dev-launch` (`devices/ipc.rs` ~119). Type trong `desktop.ts`, wrapper `devInstall`, `devOpenPair`, `devReverse`, `devPkgVersion` trong `features/devices/lib/devices.ts`.
  6. Tham khảo cách `apps/shell` gọi desk dispatch và shim (`.code_index/lookup.md` dòng 9) để kênh mới tới được web.
- Tiêu chí nghiệm thu:

  - [ ] `reverse` từ chối port sai; `package_version` parse đúng mẫu dumpsys, package sai bị từ chối.
  - [ ] Kênh đăng ký + type + wrapper; `npm run typecheck` sạch.
