- Model: opus (bảo mật ghép đôi, LAN).
- Làm:
  1. `pair_start(opts)` nhận `via: "usb"|"qr"|"lan"`, `extraLan: ["127.0.0.1"]` (chỉ cho via usb), `adbSerialHash?` (16 hex); trả thêm trường `via`. Pair xong qua via usb → lưu `adb_serial_hash` vào `Device` (serde default), xuất `adbSerialHash` trong `device_json`. `Device` thêm `paired_via`. Hộp "Cho phép" (`text.rs::pair_title` + body) ghi nguồn: "qua cáp USB" / "qua trang cài, IP x.x.x.x" / "qua mã QR".
  2. Trang tải LAN: ticket `ApkPage` → `GET /install/<t>/` trả HTML tĩnh tối giản (không JS, CSS inline, vi/en theo `Accept-Language`, `Cache-Control: no-store`, `Referrer-Policy: no-referrer`, `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'`): tên app, phiên bản, kích thước, link "Tải APK" (`orrery.apk`), link "Mở và ghép đôi" (`pair`). Chuỗi HTML đặt trong `text.rs`/file text, không comment.
  3. `GET /install/<t>/pair`: chỉ khi (a) wizard đang chờ (cờ `install_pair_armed` do web bật qua op `arm`/`disarm` của `ccm:remote-install`), (b) peer IP trùng IP đã GET APK qua ticket này, (c) chưa dùng. Khi đủ: tạo mã ghép đôi qua đường `pair_start(via:"lan")` gắn IP (handshake ghép đôi từ IP khác → từ chối, ghi access log), trả 302 tới `orrery-remote://pair?q=<urlencoded qr>`. Sai điều kiện → 403, KHÔNG tạo mã, KHÔNG thay slot ghép đôi đang chạy.
  4. Sự kiện tới web khi APK được GET lần đầu: `install.fetched {ip}` qua kênh event remote hiện có (tìm cách `onRemoteChanged` phát) để wizard đổi state.
  5. `ccm:remote-check {deviceId}` → `{lan:{ok, ms?}, relay:{state, ms?}, push:{ok, error?}}`: ms từ frame `Kind::Ping` 2 chiều (`dashboard.rs` ~220-233, `liveness.rs`): ghi thời điểm gửi/nhận, RTT gần nhất; push gọi `push_test` (`push_setup.rs` ~89) giới hạn 1 lần/30s/thiết bị (lần 2 trong 30s trả `{ok:false,error:"rate"}`).
  6. Thu hồi có hoàn tác: `ccm:remote-revoke {id, grace?: 5}` có grace → treo thiết bị ngay (đóng link đang mở, chặn handshake/connect của thiết bị đó), giữ lệnh chờ trong core; hết grace hoặc lúc app tắt (hook shutdown của Remote) → thu hồi thật. `ccm:remote-revoke-undo {id}` trong grace → bỏ treo. Không grace → như cũ.
  7. Type + wrapper web: `remotePairStart(opts)`, `remoteCheck(id)`, `remoteRevoke(id, grace?)`, `remoteRevokeUndo(id)`, op `arm`/`disarm` của install; parse + test vitest.
