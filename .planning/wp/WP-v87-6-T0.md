## WP-v87-6-T0: vỏ Tauri `apps/shell` (khung) + cookie auth

- Spec: `.planning/PLAN-v87-step6-tauri.md` (§2, §3 mục 1, 5, 11, §4 6b T0). Spike chạy được: `spikes/tauri-shell/` + `.planning/wp/WP-v87-6-spike-report.md` (Tauri 2.12.5, header tự vẽ, CDP qua `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS`). Electron hiện tại: `apps/desktop/src/main.ts` (cửa sổ, tray, single-instance, `agent-monitor://`, login item, zoom), `core-serve-host.ts`, `preload.ts`.
- Mục tiêu:
  1. Cargo workspace riêng `apps/shell` (như spike, KHÔNG vào workspace `apps/core`; phụ thuộc crate `apps/core/crates/*` qua path). Tauri 2.12.x ghim, feature `unstable`. Chạy `core-serve` trong process (thread / runtime riêng, cùng env như Electron đặt cho serve: `CCM_APP_KEY` ngẫu nhiên, `CCM_PORT` mặc định 4317 hoặc env, `CCM_DATA_DIR`, `CCM_WEB_DIST`…) và `core-pty` (như `pty/supervisor.ts` đang spawn `orrery-core`; chọn link thẳng hoặc spawn binary — ghi lý do).
  2. Cửa sổ chính: header tự vẽ (Windows, nút theo theme, snap: giữ `THICKFRAME`/`MAXIMIZEBOX`), mac `titleBarStyle: Overlay`; close → ẩn vào tray; tray + menu (như `main.ts:578-620`); `tauri-plugin-single-instance` + `tauri-plugin-deep-link` cho `agent-monitor://` (đưa link vào đúng handler, xem `openLink.ts`); `tauri-plugin-autostart`; `tauri-plugin-notification`; zoom.
  3. Cookie auth (§3 mục 1): `core-http` thêm `GET /?k=<key>` (key đúng → `Set-Cookie ccm_app=<key>; HttpOnly; SameSite=Strict; Path=/` + redirect `/`), request có cookie đúng coi như header `x-ccm-app` (HTTP + WS upgrade). Header cũ giữ nguyên cho Electron. Test Rust.
  4. Shim `window.ccmDesktop`: script init (Tauri `initialization_script`) sinh từ danh sách method / event trong `apps/desktop/src/preload.ts` bằng script `scripts/gen-desk-shim.mjs` (đọc preload, xuất `apps/shell/src/shim.js`): mỗi method → `invoke('ccm', {channel, args})`, mỗi event → `listen`. Command `ccm` trong T0 chỉ trả lỗi `not ported` (D0 sẽ nối `core-desk`), trừ các channel cửa sổ / tray / zoom / pickFolder / openExternal mà T0 tự làm. `desktop.ts` của web phải nhận shim như bridge thật (`hasTerminals` dựa vào method có mặt).
  5. Chạy dev: `npm run shell:dev` (build web, cargo run shell). CDP: `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<p>`; `apps/desktop/e2e/cdp.cjs` thêm chế độ `CCM_E2E_SHELL=tauri` (launch exe Tauri, cùng port / data tạm). Chạy được ít nhất E2E `p2` (Workspace shell pane gõ lệnh) và `agent-map` trên Tauri, ghi kết quả.
