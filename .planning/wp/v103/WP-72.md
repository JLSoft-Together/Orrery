### Việc
1. #9 Ảnh: trong danh sách file thay đổi của 1 commit (và Changes nếu cùng đường), bấm `png / jpg / jpeg / gif / webp / svg / bmp / ico` → xem ảnh trước / sau (cạnh nhau hoặc gạt), không báo "tệp nhị phân". Đọc bytes ở commit đó và commit cha qua đường đã có (git show `rev:path`), giới hạn dung lượng hợp lý, ảnh thêm / xoá hiện 1 bên. Đúng cả desktop Tauri (`apps/shell`) và Node / Electron nếu còn chung đường (twin test `desk-preview-git.twin.test.ts` phải còn pass). SVG hiện như ảnh (không chèn DOM thô).
2. #8 Xem diff nhanh từ Git Log: tự soát (mở log, chọn commit, xem file, chuyển file, đóng, quay lại, so 2 commit…) so với IntelliJ / VS Code / Fork; sửa các điểm khó dùng rõ ràng (vd. chọn commit thấy ngay danh sách file + diff file đầu, phím ↑ ↓ / j k chuyển commit / file, Enter mở diff, Esc quay lại, nhớ file đang xem khi đổi commit, diff side-by-side / inline, wrap, giữ vị trí cuộn, copy hash). Liệt kê cái đã sửa + cái cần chủ nhân chốt.
