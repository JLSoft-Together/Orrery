## WP-73: Disk — chọn item không đổi trạng thái; chọn ổ để quét không đúng (tích C vẫn quét D)

- Plan + luật chung: `.planning/PLAN-v103-next-polish.md` (mục "Luật chung", bắt buộc). Góp ý #5.
- Đọc trước: `CLAUDE.md` (đoạn v101 Disk), docs §11at, `.planning/PLAN-v101-disk-manager.md`, `.code_index/` phần disk (web `components/disk/**`, `stores/disk*`, `lib/diskMap*`; shell `apps/shell/src/disk_*.rs`; core `apps/core/crates/core-disk`).
- Model: sonnet. Song song với WP-70a, WP-72 — không đụng file của họ.

### Việc
1. Tái hiện + sửa "select item chưa đổi trạng thái": xác định danh sách nào (Clean up, Big files, Duplicates, Apps, Organize…) — kiểm tất cả danh sách có checkbox / chọn: bấm phải đổi trạng thái ngay (checkbox, nền dòng, đếm "đã chọn N"), chọn tất cả / bỏ chọn, phím Space. Tìm nguyên nhân gốc (reactivity mất do Set / Map không reactive, key sai, prop không cập nhật…), sửa chung.
2. Chọn ổ để quét: tích chỉ C thì chỉ quét C (cả quét thường lẫn "Quét siêu nhanh" MFT, quét nền khi rảnh, snapshot). Lần theo tham số từ UI → store → bridge Tauri / Electron → `core-disk` (`roots` / `drives`) — sửa nơi bỏ qua lựa chọn; nhớ lựa chọn ổ; test Rust cho lọc root + vitest cho store.
3. Test: vitest disk, `cargo test -j 4 -p core-disk`, shell `disk_` (`disk_organize` có thể chập chờn khi tải nặng → chạy riêng), E2E nếu có sẵn ca disk; ảnh `docs/qa/v103/WP-73/`.
4. Không quét ổ thật quy mô lớn khi test (dùng thư mục tạm / fixture); không xoá file thật.
