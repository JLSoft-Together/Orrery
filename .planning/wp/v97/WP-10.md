### Việc
1. Rust (`apps/mobile/rust`): thêm path dep `core-remote-proto = { path = "../../core/crates/core-remote-proto" }`; API FRB mỏng (không IO): ghép (`pair_start(qr) -> state + msg1`, `pair_finish(state, msg2) -> msg3 + desktop info | KeyMismatch`), phiên IK (`session_start`, `session_finish`), `Transport` handle (`seal`, `open`), `Chunker` / `Reassembler`, `QrPayload::decode`, `StaticKeypair` generate / import / export. Test Rust dùng `tests/vectors.json` của crate.
2. Dart `lib/remote/`:
   - `keys.dart`: key tĩnh điện thoại + `deviceId` trong `flutter_secure_storage` (`first_unlock_this_device`, không iCloud sync).
   - `machines.dart`: danh sách máy đã ghép (machineId, tên, mkey, host/port LAN cuối, relay URL, relayToken + exp) — secure storage cho token, JSON cho phần còn lại.
   - `transport_ws.dart`: `WebSocketChannel` (LAN `ws://host:port/remote`, relay `wss://…/p/<machine>?t=<token>`), handshake timeout 5 s, keepalive relay bằng text `"ping"` 30 s (ngoài Noise), ping Noise kind 3 khi LAN.
   - `connection.dart`: state machine `idle → discovering → handshaking → ready → reconnecting → offline` (+ `protoTooOld`, `revoked`); chọn đường: thử LAN (mDNS `bonsoir` `_orrery._tcp` lấy IP / port + `machineId` trong TXT, hoặc host trong QR) max 1,5 s, không được thì relay; nối lại backoff 1 → 2 → 4 → 8 → max 30 s; đổi mạng (connectivity) → nối lại ngay; app vào nền → detach PTY, đóng WS sau 30 s; về foreground → nối lại + `hello` + `resync` + `ws.get`.
   - `protocol.dart`: envelope lệnh `{id,t,…}` / reply `{re,ok,…}` / event; `Future` theo `id` có timeout 10 s; mã lỗi theo hợp đồng §4; mã đóng 44xx → state tương ứng.
   - `store.dart` (Riverpod 3): `MachineState` = snapshot dashboard (`MonitorSnapshot` dạng JSON map, áp `events` theo `seq`, hụt seq → `resync`), `ws.snapshot` + `ws.patch` (JSON Patch, lệch `rev` → `ws.get`), danh sách `confirm.ask` đang chờ; cache offline: ghi snapshot + workspace + 64 KiB tail mỗi pane đã xem vào file trong app support dir (đánh dấu `isExcludedFromBackup` trên iOS — Android đã tắt backup), đọc lại khi mở app, gắn nhãn "cũ, lúc HH:mm".
   - `pty_stream.dart`: `attach(stream, sessionId, cols, rows)` / `detach` / `input(bytes, {claim})` / `resize`; output kind 1 → `Stream<Uint8List>` theo stream id; max 4 attach.
3. Ghép bằng QR (`mobile_scanner`): màn tạm "Ghép máy" (quét → `pair` → lưu máy). Chỉ cho ghép khi QR còn hạn; không có đường nhập mã tay.
4. Gateway giả để test (PC): `apps/mobile/rust/examples/fake_gateway.rs` (hoặc test Dart với mock transport) dùng chính crate proto làm desktop: ghép, IK, trả `welcome` / `snapshot` / `ws.snapshot`, echo PTY. `flutter test` chạy logic connection / store với transport giả (không cần máy thật).
5. Build APK debug + cài lên A21s (`192.168.1.217:43169`) nếu máy mở khoá; máy khoá PIN thì ghi CHƯA KIỂM, không đổi setting máy.
