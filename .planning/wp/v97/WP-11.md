### Màn
| Màn | Nội dung |
|---|---|
| Máy | list máy đã ghép: tên, LAN / relay / offline, lần cuối; nút ghép máy mới (màn QR của WP-10); vuốt xoá |
| Workspace | AppBar tên máy + chip kết nối; list project (như rail desktop): tên, số pane, pane chờ / xin quyền nổi lên đầu (badge); chạm project → tab của project |
| Tab | `PageView` các pane theo thứ tự `leaves(tree)`, chấm vị trí; ≥ 700 dp: dựng đúng cây chia (`tree`) như desktop; header pane: icon agent, tên, status (icon + chữ + màu), tool đang chạy + thời gian (từ snapshot dashboard qua `terminalId`), chip "người gõ" |
| Pane terminal | xterm (`xterm` package, bọc trong widget `TerminalView` của mình để đổi được); attach khi pane hiện, detach khi rời / app vào nền; xoá terminal khi `pty.ready` (replay từ đầu); khung nhập dòng (TextField nhiều dòng, IME tiếng Việt) + Gửi (kind 2 + flags `claim`) + thanh phím phụ Esc / Tab / ⇧Tab / Ctrl-C / ↑ ↓ ← → / Enter (claim); nút "gõ thẳng" bật bàn phím vào terminal; pinch zoom cỡ chữ; cỡ terminal theo màn điện thoại khi đang gõ (`pty.resize`), khi chỉ xem thì giữ cỡ desktop và cho kéo ngang trong khung |
| Xin quyền | pane `asked` hiện thanh trả lời (Có / Có luôn / Không / Esc) → `ws.keys` với `since` |
| Mission Control | lưới thẻ mọi pane (theo project), lọc trạng thái, chạm mở |
| Inbox | pane chờ / xin quyền / xong việc, chạm nhảy tới |
| Mở pane | chọn project (favorites + project có trong Workspace) → Claude / Codex / shell → prompt tuỳ chọn + "gửi luôn" → `ws.open` |
| Thao tác | long-press tab / pane: đổi tên tab, đóng pane, chuyển tab, mở lại pane vừa đóng, Compact |
| Xác nhận | `confirm.ask` → bottom sheet (title, detail, ok, cancel), đếm 60 s → `confirm.answer` |
| Offline | banner "Máy offline — dữ liệu lúc HH:mm", không gõ được, tự nối lại |
| Lỗi kết nối | `revoked` → màn "Máy đã thu hồi điện thoại này" + xoá cache; `protoTooOld` → "Cập nhật app / desktop" |
