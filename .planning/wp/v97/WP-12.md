### Màn
| Viewer | Trên điện thoại |
|---|---|
| Explorer | cây thư mục lazy theo project (root = pane cwd / repo), git mark (M / A / D / ?), tìm file nhanh (`fs.files` + lọc fuzzy), mở file; watch khi mở, unwatch khi rời |
| File | xem có highlight (package `flutter_highlight` hoặc `re_highlight`, chọn cái nhẹ, ghi lý do), số dòng, tìm trong file; sửa nhẹ (TextField monospace) + Lưu với `base`; file đổi trên đĩa khi đang sửa → banner conflict, không ghi đè; nhị phân / quá lớn → thông báo |
| Changes | list file đổi (staged / unstaged), stage / unstage / discard (xác nhận), commit message + Commit; mở diff |
| Diff | unified, cuộn dọc, màu thêm / xoá theo token, gộp hunk dài |
| Git Log | list commit (graph rút gọn 1 cột màu), phân trang; chi tiết commit + file đổi + diff; branch: list, tạo, fetch, cập nhật, push (xác nhận hiện đủ nhánh đích), xoá (xác nhận) |
| Run | config của project, start / stop / reload, log (200 dòng cuối, cuộn theo), trạng thái |
| Monitor | list session theo project: trạng thái, model, tool đang chạy, subagent (cây thụt lề), context %, token chỉ khi có dữ liệu thật; chạm → mở pane trong Workspace |

Điều hướng: trong màn pane / project có menu "Explorer · Changes · Git Log · Run"; tab dưới cùng (hoặc rail trên tablet): Workspace · Monitor · Inbox.
