## WP-14: Push native FCM qua relay (Android trước, iOS sau)
- Mục tiêu: app Orrery Remote đóng / ở nền vẫn nhận thông báo khi pane cần chú ý (agent xong lượt, hỏi quyền, confirm) — chạm thông báo mở thẳng pane. Payload chỉ `{machineId, paneKey, kind}`, không nội dung session.
- Spec item: SPEC §8, PLAN T12, `docs/remote-integration.md` (thêm mục push).
- Luồng:
  1. App: `firebase_messaging` lấy FCM token (xin quyền POST_NOTIFICATIONS Android 13+ lần đầu bật, có switch trong màn máy / settings app) → gửi lệnh mới `push.register {token, platform, locale}` qua phiên Noise; token đổi (`onTokenRefresh`) → gửi lại; tắt switch → `push.unregister`.
  2. Gateway (`apps/shell/src/remote/**`): lưu token theo thiết bị trong keyring / store thiết bị hiện có (thu hồi thiết bị = xoá token). Khi có sự kiện cần chú ý (cùng nguồn đang tạo Telegram / ntfy link `pane_link`) và thiết bị đó KHÔNG có phiên đang mở → gửi qua kết nối relay `/m/<id>` control (connId 0) `{t:"push", token, data:{m, p, k}, title, body}`; title / body là chuỗi cố định theo `kind` + `locale` (vi / en), không tên file / prompt / nội dung. Max 1 push / pane / 30 s, max 30 / giờ / thiết bị.
  3. Relay (`apps/relay/src/**`): nhận control `push` chỉ từ desktop đã xác thực, rate limit theo machine, gọi FCM HTTP v1 `projects/orrery-remote/messages:send` bằng OAuth token ký JWT RS256 qua WebCrypto từ secret `FCM_SERVICE_ACCOUNT` (JSON service account, `wrangler secret put`), cache access token ~55 phút; lỗi `UNREGISTERED` → báo desktop `{t:"push.dead", token}` để xoá. Không log token / data.
  4. App: notification Android channel `attention`; chạm (cả khi app bị kill: `getInitialMessage`) → điều hướng như deep link `/o/<machine>/<pane>` hiện có (`lib/app/pane_link.dart`, `deep_link_host.dart`).
- Firebase: project id `orrery-remote`. `apps/mobile/android/app/google-services.json` do chủ nhân tải (có thể chưa có khi bắt đầu): code + Gradle plugin `com.google.gms.google-services` cấu hình sẵn; thiếu file → build vẫn phải chạy được? KHÔNG — chấp nhận cần file; ghi rõ trong README / docs. iOS: chỉ chuẩn bị code (`firebase_messaging` chung), chưa APNs key.
- Phạm vi file: `apps/mobile/**` (lib, android, pubspec, test, ARB, `.code_index/mobile.md`), `apps/shell/src/remote/**`, `apps/relay/src/**` + test + README, `packages/shared/src/remote.ts` (kiểu lệnh mới), `docs/remote-integration.md`, `docs/orrery-remote.md`, `.code_index/*`. | Cấm đụng: `apps/core/**`, `apps/web/**` (trừ khi bắt buộc — ghi báo cáo), `apps/relay/wrangler.jsonc` (main sở hữu), mọi file secret.
- Bảo mật (bất biến): service account JSON không bao giờ vào git / log / điện thoại / desktop; token FCM chỉ đi desktop ↔ relay; relay không nhận push từ phone; payload không nội dung.
- Model: sonnet (code) → review opus (relay auth + JWT + secret).
