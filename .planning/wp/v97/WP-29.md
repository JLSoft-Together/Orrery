- Việc:
  1. Theme:
     - `apps/mobile/lib/ui/theme/**`: ColorScheme + `ThemeExtension` (OrreryColors / OrreryShape / motion token) theo bảng mapping.
     - Sáng `orrery-light`, tối `galaxy`, theo chế độ máy.

  2. Component chung (thư mục mới `apps/mobile/lib/ui/kit/**`):
     - thẻ, chip trạng thái (icon + chữ + màu, đổi trạng thái animate màu + icon), nút, sheet spring, dialog;
     - banner kết nối (LAN / Relay + độ trễ, chấm nhịp khi đang nối), empty / offline / error state;
     - list animate thêm / xoá / đổi tên (AnimatedList hoặc tương đương, chỉ transform / opacity);
     - page transition spring;
     - tôn trọng `MediaQuery.disableAnimations`.
  3. Màn:
     - Home A: danh sách máy, nhóm "Đang kết nối" + "Bản trùng tên" (gộp máy cùng tên: bản đã thu hồi / offline), nút "Dọn bản cũ" (xoá bản cũ khỏi danh sách cục bộ, có xác nhận).
     - Ghép máy: QR + nhập mã, giữ ô nhập mã debug.
     - Màn khoá: hiện dần + rung nhẹ khi xác thực lỗi.
     - Logic giữ nguyên, chỉ đổi giao diện + motion.
