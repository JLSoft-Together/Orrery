  2. Workspace:
     - Mặc định A (1 pane + chip pane trượt ngang có tên + trạng thái).
     - Nút đổi view mode sang B (lưới Mission Control, mỗi pane 3 dòng output, chạm mở to). Nhớ lựa chọn.

     - Header chọn pane (`term-pick` sheet), chip trạng thái, thanh phím phụ (Esc / Tab / Ctrl / Alt / mũi tên), ô gõ + nút gửi theo mockup.

  4. Motion:
     - List thêm / xoá / đổi tên animate; chip đổi trạng thái animate.
     - Đổi view mode A ↔ B có chuyển cảnh.
     - Theo spec; tắt khi giảm chuyển động.
  5. Logic giữ nguyên: lệnh, đổi tên session / tab, chỉ xem / điều khiển, confirm nguy hiểm, permission bar.
