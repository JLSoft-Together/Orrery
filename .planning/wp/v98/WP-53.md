## WP-53: Relay phục vụ web app `/app/*` + desktop đẩy bản web khi "Cập nhật relay"

- Mục tiêu: relay Cloudflare của người dùng phục vụ web app iPhone (`apps/pwa`, làm ở WP-54) tại `https://<relay>/app/`, đóng gói chung với worker mà desktop đã deploy (§7.3), có CSP chặt + HSTS; desktop deploy / "Cập nhật relay" là đẩy luôn bản web mới.
- Spec: `.planning/PLAN-v98-ios-pwa.md` #3, #14, #25 (CSP, HSTS), WP-53. Kết quả spike: `.planning/wp/v98/WP-50a-report.md` (CSP cần `script-src 'wasm-unsafe-eval'`, `.wasm` phải `application/wasm`), `.planning/wp/v98/WP-50bc-report.md` (CSP `connect-src` với IP LAN; wildcard `wss://*:4320` chưa biết WebKit nhận không — chờ iPhone).
- Hợp đồng: `docs/remote-integration.md` §7 + §7.3, `apps/relay/README.md`, `scripts/relay-bundle.mjs`, `apps/shell/src/remote/{cf_api,relay_setup}.rs` (đọc để hiểu deploy multipart).
- Phạm vi file được đụng: `apps/relay/**` (route `/app/*` mới, test), `scripts/relay-bundle.mjs`, `apps/shell/resources/relay/**` (sinh lại), `apps/shell/src/remote/{cf_api,relay_setup}.rs` CHỈ khi cách đóng gói bắt buộc (ưu tiên không đụng Rust), `docs/remote-integration.md` (§7 thêm mục `/app/*`), `apps/relay/README.md`, `.code_index/` dòng liên quan, báo cáo. Cấm đụng: `apps/web/**`, `apps/mobile/**`, `apps/core/**`, `apps/relay/src/{room,token}.ts` trừ khi chỉ import (WP-52 sắp sửa room cho ghép qua relay).
- Model: sonnet. Song song với WP-57 (xoá iOS + docs, không đụng relay).

### Việc
1. Chọn cách đóng gói: (A) nhúng file web vào `worker.js` (module tĩnh / map path → bytes base64 hoặc `Uint8Array`, sinh bởi `relay-bundle.mjs` từ 1 thư mục dist cấu hình được, mặc định `apps/pwa/dist`, không có thì bỏ qua `/app/` và trả 404 rõ ràng); hoặc (B) Workers Static Assets qua API upload-session. Ưu tiên (A) nếu tổng gzip của worker vẫn dưới giới hạn Free plan (kiểm con số hiện hành, ghi vào báo cáo; ước lượng PWA ~1–1.5 MiB thô gồm Vue + xterm.js + wasm 223 KiB) vì không đổi luồng deploy Rust; nếu (A) không vừa thì (B) và ghi rõ các bước API. Hash bundle (`worker.json.hash`) phải đổi khi web đổi → `updateAvailable` của desktop bật đúng.
2. Route `GET /app/*` (và `HEAD`): `/app` → redirect `/app/`; SPA fallback `index.html` cho đường không có đuôi file; `content-type` đúng (`.wasm` = `application/wasm`, `.webmanifest`, `.js` module, `.css`, ảnh, font); `ETag` + `Cache-Control` (file có hash trong tên: immutable 1 năm; `index.html`, `sw.js`, manifest: `no-cache`); gzip / brotli nếu chọn được theo `accept-encoding` (hoặc để Cloudflare nén, ghi rõ).
3. Header bảo mật cho mọi phản hồi `/app/*`: CSP `default-src 'none'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self'; img-src 'self' data: blob:; font-src 'self'; connect-src 'self' wss://<host relay> <nguồn LAN>; worker-src 'self'; manifest-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`, `<nguồn LAN>` tạm là `wss://*:4320 https://*:4320` qua 1 hằng dễ đổi (chờ iPhone trả lời wildcard IP; nếu WebKit không nhận thì WP-54 / WP-51 sẽ đổi sang cách khác — ghi rủi ro). `Strict-Transport-Security: max-age=31536000`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Permissions-Policy` chỉ mở `camera=(self)`. `sw.js` thêm `Service-Worker-Allowed: /app/`.
4. Endpoint `GET /app/version.json` (no-store) = `{web: <hash bản web>, proto: <PROTO>, minProto}` để web app tự so và hiện thanh "Có bản mới — tải lại" (#14).
5. Test vitest (`@cloudflare/vitest-plugin` như test hiện có): content-type, CSP / HSTS có mặt, SPA fallback, 404 khi không có bản web, path traversal (`/app/../x`, `%2e%2e`, backslash) không thoát ra ngoài map, ETag 304, `version.json`. Thư mục fixture nhỏ làm bản web mẫu.
6. `node scripts/relay-bundle.mjs` chạy được cả khi có / không có dist; in kích thước thô + gzip; nếu vượt ngưỡng an toàn (đặt ~80% giới hạn) thì fail rõ ràng.
7. Docs: `docs/remote-integration.md` §7 mục mới "Web app `/app/*`" (đóng gói, header, version.json, cách cập nhật); `apps/relay/README.md` bảng route thêm dòng.
