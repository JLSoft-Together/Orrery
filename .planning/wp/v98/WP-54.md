0. Đọc `CLAUDE.md` mục Hard rules (i18n `vi` + `en`, màu chỉ qua token, trạng thái = icon + chữ + màu, không blur / gradient, font hệ thống) và nạp skill `frontend-design:frontend-design` + `ui-ux-pro-max:ui-ux-pro-max` trước khi làm phần UI.
1. 2. Wasm: script `npm run wasm -w @ccm/pwa` build `core-remote-wasm` (release, `wasm32-unknown-unknown`, `wasm-bindgen --target web`, dùng binary wasm-bindgen WP-50a đã cài) vào thư mục sinh gitignored; `build` tự gọi khi thiếu. Ghi kích thước dist (thô + gzip) vào báo cáo.
3. Lớp kết nối (`src/remote/`), tách khỏi Vue, test được bằng Vitest: `NoiseLink` bọc wasm; `Dialer` relay (`wss://<relay>/p/<machineId>?t=<token>`) và LAN (`wss://<ip>:4320/remote`, dùng thật ở WP-51 — bây giờ chỉ cần chạy với server giả); chính sách đường "Tự động / Chỉ LAN / Chỉ relay" (Tự động: thử LAN ~3 s nếu có IP LAN đã biết, không thì / lỗi thì relay; mất LAN tự về relay); keepalive + timeout như §1; reconnect backoff khi Safari treo socket lúc nền (`visibilitychange` / `pageshow` → nối lại ngay); xử lý mã đóng §6 (`4401` = thiết bị bị thu hồi → xoá sạch dữ liệu máy đó, `4426` = cần cập nhật).
4. Store (Pinia): danh sách máy đã ghép (nhiều máy), trạng thái đường của từng máy, snapshot Monitor + Workspace và áp patch theo §4 (port logic từ `monitor_reducer.dart` / `json_patch.dart`; hàm thuần, test kỹ), activity cap như desktop.
5. Lưu trữ: IndexedDB (1 wrapper nhỏ, không thư viện nặng): khoá tĩnh thiết bị bọc AES-GCM bằng `CryptoKey` không trích xuất được (WebCrypto, cũng cất IndexedDB); danh sách máy; snapshot cuối mỗi máy (đọc lại khi mở app, đánh dấu cũ). Thu hồi / xoá máy = xoá sạch mọi bản ghi của máy đó. Khoá WebAuthn là WP-55 — để chỗ móc (`unlock()` trả khoá giải mã) nhưng chưa làm UI.
