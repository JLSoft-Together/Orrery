- Phạm vi file được đụng: xoá `apps/mobile/ios/**`; sửa trong `apps/mobile/**` những chỗ chỉ dành cho iOS (vd. `.metadata` platforms, `pubspec.yaml` mục iOS, code Dart `Platform.isIOS` / `TargetPlatform.iOS` chỉ phục vụ iOS native, cấu hình flutter_launcher_icons / native_splash iOS, script build iOS) — giữ hành vi Android y nguyên; `apps/mobile/.code_index/mobile.md`; `docs/orrery-remote.md`; `docs/remote-integration.md` (chỉ các dòng nói về iOS native: `CFBundleURLTypes`, Associated Domains, APNs, `GoogleService-Info.plist`, `platform: "ios"`); `.code_index/_meta.md`; báo cáo. ### Việc
1. Tìm mọi tham chiếu iOS native (Grep `ios`, `iOS`, `isIOS`, `TargetPlatform.iOS`, `Runner`, `xcode`, `CFBundle`, `APNs`, `GoogleService-Info`, `applinks`) trong phạm vi được đụng; liệt kê trong báo cáo cái nào xoá / giữ + lý do. Giao thức `push.register platform: "ios"`: giữ giá trị trong hợp đồng nếu desktop còn chấp nhận (không đụng shell), chỉ ghi chú docs là app Flutter không còn gửi `ios`; web app sẽ dùng kênh Web Push riêng (WP-56).
2. Xoá `apps/mobile/ios/`. Code Dart: nhánh chỉ cho iOS native thì bỏ nếu không ảnh hưởng Android / test; nhánh dùng chung (vd. `Platform.isAndroid || Platform.isIOS`) thì đơn giản hoá cẩn thận.
3. `docs/orrery-remote.md`: §1 Tình trạng + §11 Cài app: iPhone / iPad = web app trên relay (đang làm, v98), không có app iOS native, không cần Apple Developer; thêm mục "Web app iPhone và relay — đánh đổi": web app tải từ relay của chính người dùng (Cloudflare của họ), ai kiểm soát tài khoản Cloudflare có thể sửa code web app → bật 2FA Cloudflare, giữ token kín; mã hoá đầu cuối vẫn là Noise nhưng code chạy Noise do relay phát. Các bước cài web app / cài CA LAN chưa chốt → ghi "sẽ bổ sung ở v98" một dòng, không bịa bước.
4. `docs/remote-integration.md`: sửa các dòng iOS native ở §7.1 / §7.2 cho đúng thực tế mới (app Android; iPhone = web app, §… sẽ bổ sung).
5. `apps/mobile/.code_index/mobile.md` + `.code_index/_meta.md`: 1–2 dòng.
6. Kiểm: `node apps/mobile/scripts/check.mjs` (analyze + flutter test; KHÔNG chạy flutter test thô). Không build APK.
