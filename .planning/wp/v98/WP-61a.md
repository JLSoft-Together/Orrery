## WP-61a: web app — thao tác pane (đóng / đổi tên / di chuyển / compact / mở lại) + desktop báo quyền điều khiển trong `hello` + sửa trạng thái "đang chờ duyệt" khi Từ chối native

- Mục tiêu: web app (`apps/pwa`) làm được các thao tác pane như app Android; biết ngay từ `hello` là điều khiển từ xa đang tắt (vào chế độ chỉ xem không cần chờ `denied`); bấm Từ chối trên hộp duyệt ghép native thì web hiện "bị từ chối" thay vì kẹt "đang chờ duyệt".
- Spec: `.planning/PLAN-v98-ios-pwa.md`; việc dở ghi ở `.planning/wp/v98/WP-55b-report.md` mục "Việc dở / cần desktop" và `WP-52-report.md` / PROGRESS v98 dòng "Còn dở: Từ chối trên hộp native → bảng web vẫn đang chờ duyệt". Docs: `docs/remote-integration.md` (§ lệnh `ws.*`, §5 ghép), `.code_index/web-pwa.md`, `.code_index/shell.md`.
- Mẫu tham chiếu (đã chạy): Android `apps/mobile/lib/**` dùng `ws.close`, `ws.rename`, `ws.move`, `ws.compact`, `ws.reopen` — đọc đúng tham số / phản hồi / xác nhận nguy hiểm từ đó và handler desktop `apps/shell/src/remote/**` (đã hỗ trợ đủ, đừng đổi hợp đồng các lệnh này).
- Code: `apps/pwa/src/{views/WorkspaceView.vue,components/PaneCard.vue,components/PaneSwitchSheet.vue,lib/workspaceModel.ts,remote/hub.ts,remote/connection.ts,stores/**,i18n/{en,vi}.ts}`, màn ghép (tìm theo "pending" / `pair`), desktop `apps/shell/src/remote/**` (chỗ dựng `hello`), `core-remote-proto` nếu `hello` có kiểu ở đó, Android chỉ đọc `hello` mới nếu cần (trường mới phải tuỳ chọn — app cũ bỏ qua được).
- Phạm vi được đụng: các chỗ trên + test + e2e `apps/pwa/e2e/**` (kể cả peer `e2e/peer`), docs mục liên quan, `.code_index/`, `docs/qa/v98/WP-61a/**`, báo cáo. Cấm đụng: phần viewer file / git / run của pwa (`components/Viewer*.vue`, `lib/viewer*.ts` — gói WP-61b), `apps/relay/**`, `apps/web/**`, `scripts/spike-v98/**`, `apps/mobile/ios`.
- Model: sonnet. Chạy song song với WP-62 (WP-62 đụng relay + dọn `platform: ios`; nếu cùng phải sửa `apps/shell/src/remote/devices.rs` thì chỉ sửa phần `hello`, ghi lại).

### Việc
1. Pane: menu thao tác trên thẻ pane / màn pane: Đổi tên, Di chuyển (sang tab / nhóm như Android), Compact (theo luật ngoại lệ v51: chỉ khi desktop cho phép — giữ đúng hành vi Android), Đóng (xác nhận bằng `BottomSheet` / ConfirmHost; sau đóng có "Hoàn tác" gọi `ws.reopen` nếu desktop trả id). Cập nhật state qua `ws.patch` như hiện có, có chuyển động khi thêm / bớt / đổi tên (luật UI: mọi thay đổi có motion).
2. `hello`: desktop thêm trường tuỳ chọn báo điều khiển từ xa bật / tắt (tên do bạn chọn, ghi docs); web vào chỉ xem ngay khi tắt, cập nhật khi đổi nếu desktop có event (nếu chưa có event thì chỉ ở `hello` + `denied`, ghi lại). Test Rust cho `hello`.
3. Ghép: khi người dùng Từ chối trên hộp native, web nhận lỗi / đóng kết nối nào → hiện trạng thái "Máy đã từ chối" có nút thử lại; tìm đúng nguyên nhân kẹt (đọc luồng ghép relay + LAN), sửa ở phía cần sửa.
4. i18n `en` + `vi` cho mọi chuỗi mới (từ ngữ theo GLOSSARY: giữ `pane`, `compact`; không em dash, không chấm giữa).
5. Test: vitest (model thao tác, hello cờ, trạng thái từ chối), E2E Playwright WebKit + Chromium thêm ca: đổi tên, đóng + hoàn tác, di chuyển, chỉ xem từ `hello`, từ chối ghép. Ảnh phone + iPad sáng / tối vào `docs/qa/v98/WP-61a/`.
