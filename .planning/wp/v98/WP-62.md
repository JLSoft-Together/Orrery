## WP-62: dọn phần iOS native còn sót sau WP-57

- Mục tiêu: sau khi bỏ app iOS native (WP-57, iPhone = web app), xoá mọi dấu vết không còn dùng: relay AASA / `APPLE_APP_ID`, `platform: ios` ở desktop, `cupertino_icons`; desktop nhận đúng `platform: web` (hiện ra `unknown`).
- Spec: `.planning/wp/v98/WP-57-report.md` mục "dọn sau", `WP-55a-report.md` ("`platform: web` desktop hiện `unknown` — `devices.rs known_platform`"). Docs: `docs/remote-integration.md`, `docs/orrery-remote.md`, `.code_index/`.
- Code: `apps/relay/src/**` (route `/.well-known/apple-app-site-association`, env `APPLE_APP_ID`, `wrangler.toml`), `apps/shell/src/remote/devices.rs` (`known_platform`) + chỗ hiện nền tảng trong `apps/web` (icon / nhãn thiết bị Settings → Điện thoại), `apps/mobile/pubspec.yaml` (`cupertino_icons` nếu không còn import), docs.
- Phạm vi được đụng: các chỗ trên + test, docs, `.code_index/`, báo cáo. Cấm đụng: `apps/pwa/**`, `apps/shell/src/remote/` ngoài `devices.rs` (WP-61a đang sửa phần `hello` song song), `scripts/spike-v98/**`.
- Thư mục `apps/mobile/ios/` đang untracked trên máy (chỉ `Flutter/` + `Runner/`, do `flutter` tự sinh lại): KHÔNG xoá — chỉ thêm vào `apps/mobile/.gitignore` (dòng `/ios/`) để không bị commit nhầm, ghi báo cáo.
- Model: sonnet. Chạy song song với WP-61a.

### Việc
1. Relay: bỏ AASA + `APPLE_APP_ID` (code, `wrangler.toml`, test, docs). Kiểm không còn tham chiếu (`rtk proxy rg -n "APPLE_APP_ID|apple-app-site|cupertino" apps docs`).
2. Desktop: `known_platform` nhận `web` (giữ `android`; `ios` bỏ hoặc map về `web` cho thiết bị đã lưu — chọn, ghi lý do để không vỡ `devices.json` cũ); UI Settings hiện nhãn / icon đúng cho web app, i18n `en` + `vi`.
3. Mobile: bỏ `cupertino_icons` nếu không còn dùng; `node apps/mobile/scripts/check.mjs` sạch.
4. Test: relay `npm test -w <relay>` (số, so 64), `cargo test --bin orrery-shell remote::devices` hoặc nhóm liên quan (số), web vitest file liên quan + typecheck, `check.mjs` (số, so 295).

### Luật (bắt buộc)
- Không viết comment trong code (mọi loại, kể cả TODO).
- Không `git commit` / `push`. Không deploy relay, không `wrangler login`.
- Tool nặng ≤ 80% CPU / RAM: `cargo -j 4`; trước khi chạy cargo kiểm `tasklist | grep -i cargo` (WP-61a có thể đang build — chờ). Sau `cargo build` shell: `git checkout -- apps/shell/permissions/autogenerated`. Không dùng cổng 4320–4322.
- Đừng chạy `apps/mobile/tool/gen_arb.mjs`.
- Bash: dùng tool Grep hoặc `rtk proxy rg`. Tắt tiến trình nền khi xong.
