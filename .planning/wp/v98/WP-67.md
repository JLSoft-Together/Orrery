### Việc
1. **Settings → Điện thoại trong UI next**: cùng component nhưng dùng lớp / token next (glass-pop cho popover / dialog, palette 8 màu, motion full / reduced / off); ghép QR, danh sách thiết bị, chuông push, relay, chặn IP / tin cậy / nhật ký đều dùng được và đẹp trong next sáng / tối.
2. **Trạng thái điện thoại trong khung next**: vị trí theo flow v102 (rail / header next / Ctrl+K) — ví dụ chip "Điện thoại" (số máy đang nối, push, cảnh báo chặn IP) và mục Ctrl+K "Ghép điện thoại", "Thiết bị đã ghép". Chọn vị trí theo SPEC v102, ghi lý do.
3. **Pane từ điện thoại khớp UI next**: `ws.open` / `ws.move` / `ws.rename` / `ws.close` / `ws.reopen` đi qua đúng mô hình nhóm project (`GroupNode`), layout preset, Undo toast, drop compass của next. 4. Click menu v100: pane mở từ điện thoại có thanh trả lời như pane thường; phím gửi từ điện thoại không đè thanh click.
5. Classic: không đầu tư, chỉ không vỡ build / test.
6. Test: vitest web (remote + next), E2E desktop `apps/desktop/e2e` chế độ next (`launch({ ui: 'next' })`, xem `v102-next.cjs`) thêm ca Settings → Điện thoại + chip trạng thái; `cargo test` shell nếu đụng. Ảnh next sáng / tối 2–3 palette `docs/qa/v98/WP-67/`.
