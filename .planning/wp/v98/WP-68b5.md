### Việc
1. `npm run e2e -w @ccm/pwa -- --relayPort=8795 --inspectorPort=9355` (build lại peer). `STEPS_PER_BROWSER`: b3 nói 47→48, b4 nói 44→47 — gộp đúng số bước thật. Sửa lỗi selector / assertion cũ (`machine-counts` thêm chip lỗi / xong, `row-t2` chỉ ở chế độ Trạng thái, bước mới `mist-home-steps.mjs` / `mist-ws-steps.mjs`) — sửa test khi hành vi mới đúng theo mockup, sửa code khi code sai. Đạt 2 engine, 0 vi phạm CSP.
2. Ảnh phone + iPad sáng / tối + 1 palette khác cho mọi màn của b3 (`docs/qa/v98/WP-68b3/`) và b4 (`docs/qa/v98/WP-68b4/`); tự soi từng ảnh cạnh ảnh mockup cùng màn, sửa lệch rõ ràng (khoảng cách, màu, thứ tự, chữ tràn, tràn ngang, nút bị che). Ghi bảng "màn → khớp / lệch còn lại".
3. Đo cuộn danh sách dài + terminal output nhanh (rAF / trace) trên WebKit, ghi số.
4. `cargo test -j 4 --bin orrery-shell remote::` trong `apps/shell` (b3 sửa `ctx.rs` `welcome()` thêm `os`); kiểm Android chịu trường `os` mới (`node apps/mobile/scripts/check.mjs`, chỉ cần parse không lỗi).
5. Sau E2E: `git checkout --` ảnh cũ bị ghi đè trong `docs/qa/v98/WP-55b|56a|61a|61b|65|68b1/`.
6. Build web app + sinh lại bundle relay: `npm run build -w @ccm/pwa && CCM_PWA_DIST=apps/pwa/dist node scripts/relay-bundle.mjs`; kiểm `apps/shell/src/remote/relay_setup_tests.rs` còn pass.
