# Lịch sử tính năng Orrery (v1 đến v108)

Chuyển nguyên văn từ mục "What this is" của CLAUDE.md (v110 P4). Từ v110 vỏ desktop là Tauri + `apps/core` (Rust); Electron `apps/desktop` và collector Node `apps/collector` đã xoá, nên các tên đó dưới đây là lịch sử. Catalog tính năng hiện tại: `.code_index/features.md`.

**Orrery** (renamed from Claude Code Monitor on 2026-10-11, then Agent Monitor → GolAIm on 2026-10-15, then GolAIm → Orrery on 2026-10-17, an orrery is the clockwork model of planets circling a sun, like sub-agents around their main agent; userData stays pinned to the `Agent Monitor` folder; repo folder, npm package names `@ccm/*`, `appId` `dev.ccm.monitor`, data dir `ccm`, `CCM_*` env and `ccm.*` storage keys keep the old prefix on purpose so installs update in place). A local-only desktop app (Windows exe, macOS `.dmg`; no browser mode since v2.0.0) that observes running Claude Code CLI sessions (target version **2.1.289**), plus Codex CLI runs (**0.162.0**), shown under the Claude agent that launched them, across multiple terminals and shows sessions, terminal titles, and the main-agent → sub-agent hierarchy in realtime. Since v28 an Extensions tab installs curated MCP servers / plugins into Claude Code (global or per project) only via the `claude` CLI after a native confirm (docs §11r). Since v30 a Git Log pane shows a project's history (docs §11s); since v36 its Branches toolbar can also create, fast-forward, fetch and delete branches (delete only after a native confirm). Since v59 the Explorer tree shows Atom Material file / folder icons as in IntelliJ with that JetBrains plugin (MIT, bundled by `scripts/gen-file-icons.mjs`; Settings → Appearance → File icons switches back to Simple) (`.planning/PLAN-v59-file-icons.md`). Since v58 Settings holds several GitHub accounts added by personal access token (sealed by the OS keychain, never sent back to the page); push / fetch / pull of a github.com https remote use the repo's account, picked in the Push dialog or automatically by access (`.planning/PLAN-v58-github-accounts.md`). Since v49 a Claude session in a Workspace pane can open new panes through the PTY host's MCP server `orrery`, tool `open_session` (per-pane token, prompt only prefilled, never submitted unless the agent passes `submit: true`, owner 2026-11-08), and `agent-monitor://open` does the same from outside without a confirm (owner decision; 10 links a minute, `resume=<uuid>` reopens an unfinished session, no prompt) (docs §11w). Since v50 split tabs show as groups in the rail, tabs can be named, status counts running subagents, and deletes disintegrate into dust (`.planning/PLAN-v50-workspace-groups.md`). Since v52 a pane can be zoomed to fill its tab, closes can be undone (agents come back with `--resume`, dust flies back together), rows and headers show the running tool and time, pane headers collapse by container width, inactive panes can be dimmed, and (removed in v103) Mission Control filled the screen with filter and 1–9 keys (`.planning/PLAN-v52-workspace-polish.md`). Since v60 the Monitor center can show the Habblaud pixel-art office (one room per project, a character per agent, social life, sound, day timelapse; vendored as `packages/habblaud`, MIT) (`.planning/PLAN-v60-habblaud-office.md`). Since v61 a Devices tab connects Android devices over USB / Wi-Fi (pair code, QR, mDNS discover, remembered devices with auto-connect) through the SDK's adb (`.planning/PLAN-v61-adb-devices.md`). Since v62 the file editor can auto save as VS Code `files.autoSave` (off by default; after a delay, on focus change or on window change; never over a disk conflict; with it on, closing a pane or quitting saves instead of asking) (`.planning/PLAN-v62-auto-save.md`). Since v81 a Workspace pane can run the DeepSeek CLI Codewhale (preset `deepseek`, also via `open_session`); Settings → DeepSeek installs it, logs in and syncs rules / skills / MCP from Claude, and a DeepSeek pane hands finished work back with MCP `hand_back` (docs §11am, `docs/deepseek-integration.md`, `.planning/PLAN-v81-deepseek.md`). Since v100 the owner can answer a Claude / Codex choice menu with the mouse in a Workspace pane: hover, click (moves the highlight) and double click (selects) on a menu row read from the live terminal screen, a button bar under the pane, a "Chờ trả lời" queue chip (Ctrl+Alt+Q jumps to the next asking pane), and an OS toast with answer buttons while Orrery is not focused (Settings → Workspace switches `clickMenu` / `menuToast`, on by default; off = old text selection) (docs §11as, `.planning/PLAN-v100-click-menu.md`). Since v101 a Disk view (opened from Settings → Data → Disk) maps and cleans drives: the Rust engine `core-disk` scans in parallel into a compressed on-disk index (`CCM_DATA_DIR/disk/`) with instant search, Windows NTFS "Quét siêu nhanh" reads the MFT through a one-shot UAC helper, treemap / sunburst, Clean up (dev / system junk, SDK / emulator, Docker), duplicate files (BLAKE3), Organize Downloads with Undo, Apps with uninstall, RAM, move a folder to another drive leaving a junction, snapshots to compare, idle background rescan, Telegram report, and MCP `disk_search` / `disk_usage` / `disk_propose_delete`; every delete goes through a canonical path guard and a native dialog, Recycle Bin / Trash by default, and cloud-only files are never opened (docs §11at, `.planning/PLAN-v101-disk-manager.md`). Since v102 an opt-in UI next gen "Sương kính" (Settings → Appearance → Try the new UI (UI next gen) or Ctrl+K, root `data-ui="next"`, key `ccm.uiGeneration`, switches live without remounting panes; UI next is the default since v103; classic is frozen since 4.0.8 and is removed in 4.1.0) replaces the header with a live session rail (264 / 248 / 56 px or overlay by width, needs list, groups by project or status), an Explorer drawer (Ctrl+Shift+E, can be pinned), a Ctrl+K grouped by session state, a drop compass with snap, layout presets and an Undo toast when moving panes, glass chrome over a static mist background, 5 palettes plus Ngẫu nhiên and Tự chọn (8 cards, v108) with light / dark and motion full / reduced / off (`.planning/PLAN-v102-mist-redesign.md`, `.planning/SPEC-v102-mist-ui.md`).
