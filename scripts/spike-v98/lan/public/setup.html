Cài CA Orrery spike

Trang này là http thường, chỉ để tải hồ sơ CA. Mở bằng Safari (không dùng Chrome / app khác).

1. Tải hồ sơ CA
  1. Safari hỏi "Cho phép tải hồ sơ cấu hình?" → Cho phép → Đóng.
  2. Cài đặt → dòng Đã tải về hồ sơ ở đầu (hoặc Cài đặt chung → VPN & Quản lý thiết bị) → Orrery spike CA → Cài đặt, nhập mã máy, Cài đặt lần nữa.
  3. Cài đặt → Cài đặt chung → Giới thiệu → Cài đặt tin cậy chứng nhận (cuối trang) → bật Orrery spike CA → Tiếp tục.
  4. Quay lại Safari, mở trang test https bên dưới. Không được hiện cảnh báo "kết nối không riêng tư".
